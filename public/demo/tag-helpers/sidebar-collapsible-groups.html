Dashboard

Whole sidebar groups collapse here. Each sa-sidebar-group-label is wrapped in a <button> that toggles a sa-collapsible around the group's sa-sidebar-group-content via the Invoker Commands API. Platform starts open and Resources starts collapsed; the chevron flips with the group's aria-expanded state.
