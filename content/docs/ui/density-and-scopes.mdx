A theme sets its [theme variables](/docs/ui/theme-variables) on `:root`, so they apply to the whole page. You can also set them on a single element. The content of that element then uses the new values, and the rest of the page keeps the theme. For example, you can make a table denser than the rest of the page, or give a panel your brand colors.

## Changing the density

To change the spacing and the size of the controls inside an element, add the `data-sa-density` attribute to it, with one of the following values:

| Value | Density |
| --- | --- |
| `compact` | The theme's density multiplied by 0.8 |
| `comfortable` | The theme's density multiplied by 1.2 |

## Setting a specific density

To set a density other than `compact` and `comfortable`, add the `data-sa-scope` attribute to the element, and set `--sa-density` on it. We suggest a value between 0.7 and 1.4, the range of the theme builder.

The example below sets `--sa-density` to 0.7, 1 and 1.4:

<Demo src="/demo/ui/theming-custom-density.html">
  <include>./components/_include/theming-custom-density.mdx</include>
</Demo>

`--sa-density` on a `data-sa-scope` element replaces the theme's density. A `data-sa-density` attribute multiplies the density of the element it's in, including a `data-sa-scope` element's.

## Theming part of a page

To give an element its own theme, add the `data-sa-scope` attribute to it, and set the theme variables on it, either in a `style` attribute or in your own CSS. Everything inside the element uses them, such as the accent color, the grays, the corner radius and the density.
