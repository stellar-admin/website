## Add to existing project

The following installation instructions assume you are adding StellarAdmin to an existing ASP.NET Core MVC or Razor Pages project.

<Steps>
    <Step>
        ### Install package

        Install the StellarAdmin.UI NuGet package.

        <Tabs items={['.NET CLI', 'Package Manager']}>
            <Tab>
                ```text
                dotnet add package StellarAdmin.UI
                ```
            </Tab>
            <Tab>
                ```text
                Install-Package StellarAdmin.UI
                ```
            </Tab>
        </Tabs>
    </Step>
    <Step>
        ### Register services

        Update your `Program.cs` (or `Startup.cs`) to register the StellarAdmin services.

        ```cs
        using StellarAdmin.UI;

        builder.Services.AddStellarAdminUI();
        ```
    </Step>
    <Step>
        ### Update imports

        Update your `_ViewImports.cshtml` to register the StellarAdmin Tag Helpers and import the `StellarAdmin.UI` namespace.

        ```razor
        @using StellarAdmin.UI
        @addTagHelper *, StellarAdmin.UI
        ```
    </Step>
    <Step>
        ### Add stylesheet and JavaScript file

        Add the StellarAdmin stylesheet and the [StellarAdmin JavaScript file](/docs/ui/javascript) to your Razor page. The stylesheet carries every component and the default theme.

        ```razor
        <!DOCTYPE html>
        <html lang="en">
        <head>
            ...
            <link rel="stylesheet" href="/_content/StellarAdmin.UI/stellar-admin.css" asp-append-version="true"/>
            <script defer src="/_content/StellarAdmin.UI/stellar-admin.js" asp-append-version="true"></script>
        </head>
        <body>
            ...
        </body>
        </html>
        ```

        <Callout type="idea">
            To change the default theme, create a theme file in the [theme builder](/theme-builder) and link it after the stylesheet. The [Theming page](/docs/ui/theming) provides more information on theming.
        </Callout>
    </Step>
    <Step>
        ### Start using the Tag Helpers

        Start using the StellarAdmin Tag Helpers inside your Razor Pages or MVC Views. For example, the code snippet below adds an alert to your page.

        ```razor
        <sa-alert>
            <sa-alert-title>Success! You have configured StellarAdmin correctly.</sa-alert-title>
        </sa-alert>
        ```
    </Step>

</Steps>

Before you start using the components, read the [Conventions](/docs/ui/conventions) page. It covers the rules every Tag Helper follows for attribute pass-through, custom classes, model binding and links.
