## Add to existing project

The following installation instructions assume you are adding StellarAdmin to an existing ASP.NET Core MVC or Razor Pages project.

<Steps>
    <Step>
        ### Install package

        Install the StellarAdmin.UI NuGet package.

        <Tabs items={['.NET CLI', 'Package Manager']}>
            <Tab>
                ```text
                dotnet add package StellarAdmin.UI
                ```
            </Tab>
            <Tab>
                ```text
                Install-Package StellarAdmin.UI
                ```
            </Tab>
        </Tabs>
    </Step>
    <Step>
        ### Register services

        Update your `Program.cs` (or `Startup.cs`) to register the StellarAdmin services.

        ```cs
        using StellarAdmin.UI;

        builder.Services.AddStellarAdminUI();
        ```

        `AddStellarAdminUI()` also changes the MVC options for the whole app: it adds a model binder and a value provider that bind checkbox groups, and a global result filter that sends queued [toasts](/docs/ui/components/toast) in a response header for fetch and XHR requests.
    </Step>
    <Step>
        ### Update imports

        Update your `_ViewImports.cshtml` to register the StellarAdmin Tag Helpers and import the `StellarAdmin.UI` namespace.

        ```razor
        @using StellarAdmin.UI
        @addTagHelper *, StellarAdmin.UI
        ```
    </Step>
    <Step>
        ### Add stylesheet and JavaScript file

        Add the StellarAdmin stylesheet and the [StellarAdmin JavaScript file](/docs/ui/javascript) to your Razor page. The stylesheet carries every component and the default theme.

        ```razor
        <!DOCTYPE html>
        <html lang="en">
        <head>
            ...
            <base href="~/"/>
            <script type="importmap"></script>
            <link rel="stylesheet" href="/_content/StellarAdmin.UI/stellar-admin.css" asp-append-version="true"/>
            <script type="module" src="/_content/StellarAdmin.UI/stellar-admin.js" asp-append-version="true"></script>
        </head>
        <body>
            ...
        </body>
        </html>
        ```

        The import map gives the browser cacheable, versioned URLs for the modules `stellar-admin.js` imports. ASP.NET fills it from the static asset manifest, which takes three things:

        - `<base href="~/"/>` before the import map. ASP.NET writes the map's entries relative to the page, so without the base tag they match nothing on pages below the site root. The base tag also makes every relative URL on the page resolve against the site root, including `href="#section"` links and relative htmx URLs, so write those as absolute paths (`href="/orders#totals"`) or generate them with `asp-page`, `asp-action` or `Url`.
        - `app.MapStaticAssets()`, and `.WithStaticAssets()` on the endpoints that render pages, such as `app.MapRazorPages().WithStaticAssets()`.
        - In an MVC app, `app.MapControllers().WithStaticAssets()`. `.WithStaticAssets()` on `MapControllerRoute`, which the .NET templates use, has no effect ([dotnet/aspnetcore#59003](https://github.com/dotnet/aspnetcore/issues/59003)).

        Without these the scripts still work, but the browser revalidates each module on every page load. Content that htmx swaps into the page needs none of this, because the import map stays in effect for the whole document.

        <Callout type="idea">
            To change the default theme, create a theme file in the [theme builder](/theme-builder) and link it after the stylesheet. The [Theming page](/docs/ui/theming) provides more information on theming.
        </Callout>
    </Step>
    <Step>
        ### Start using the Tag Helpers

        Start using the StellarAdmin Tag Helpers inside your Razor Pages or MVC Views. For example, the code snippet below adds an alert to your page.

        ```razor
        <sa-alert>
            <sa-alert-title>Success! You have configured StellarAdmin correctly.</sa-alert-title>
        </sa-alert>
        ```
    </Step>

</Steps>

Before you start using the components, read the [Conventions](/docs/ui/conventions) page. It covers the rules every Tag Helper follows for attribute pass-through, custom classes, model binding and links.
