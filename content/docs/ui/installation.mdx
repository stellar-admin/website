import { Tab, Tabs } from "fumadocs-ui/components/tabs";

To install StellarAdmin.UI, you need an ASP.NET Core MVC or Razor Pages app running on .NET 10 or later.

<Steps>
    <Step>
        ### Install the package

        Add the `StellarAdmin.UI` package:

        <Tabs items={['.NET CLI', 'Package Manager']}>
            <Tab>
                ```text
                dotnet add package StellarAdmin.UI
                ```
            </Tab>
            <Tab>
                ```text
                Install-Package StellarAdmin.UI
                ```
            </Tab>
        </Tabs>
    </Step>
    <Step>
        ### Register the services

        Call `AddStellarAdminUI()` in `Program.cs` to register the services the Tag Helpers need.

        ```cs
        using StellarAdmin.UI;

        builder.Services.AddStellarAdminUI();
        ```

        <Callout type="info">
            `AddStellarAdminUI()` changes the MVC options for your whole app, including pages that don't use StellarAdmin.UI. It adds a model binder and a value provider that bind [checkbox groups](/docs/ui/components/checkbox-group), and a global result filter that sends queued [toasts](/docs/ui/components/toast) in a response header for fetch and XHR requests.
        </Callout>
    </Step>
    <Step>
        ### Register the Tag Helpers

        Add the following lines to your `_ViewImports.cshtml` to register the Tag Helpers and import the `StellarAdmin.UI` namespace:

        ```razor
        @using StellarAdmin.UI
        @addTagHelper *, StellarAdmin.UI
        ```
    </Step>
    <Step>
        ### Add the stylesheet and the script

        Add the StellarAdmin.UI stylesheet and [script](/docs/ui/javascript) to the `<head>` of your layout. The stylesheet contains the styles of every component and the default theme.

        ```razor
        <!DOCTYPE html>
        <html lang="en">
        <head>
            ...
            <link rel="stylesheet" href="/_content/StellarAdmin.UI/stellar-admin.css" asp-append-version="true"/>
            <script type="module" src="/_content/StellarAdmin.UI/stellar-admin.js" asp-append-version="true"></script>
        </head>
        <body>
            ...
        </body>
        </html>
        ```

        <Callout type="idea">
            To give your app its own look, create a theme file in the [theme builder](/theme-builder) and link it after the stylesheet. See [theming](/docs/ui/theming) for more.
        </Callout>
    </Step>
    <Step>
        ### Use the Tag Helpers

        Add a Tag Helper to one of your pages or views to check that everything works. The example below adds an alert:

        ```razor
        <sa-alert>
            <sa-alert-title>StellarAdmin.UI is installed.</sa-alert-title>
        </sa-alert>
        ```
    </Step>
</Steps>
