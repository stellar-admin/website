title: Agent Skills
description: Teach your coding agent to build UIs and themes with StellarAdmin.UI
---

StellarAdmin.UI has two skills that teach coding agents, such as Claude Code and Codex, how to use it:

| Skill | Teaches the agent to |
| --- | --- |
| `stellar-admin-ui` | Install StellarAdmin.UI in your app, and build pages with the Tag Helpers: components, forms, layouts, icons, JavaScript and templated views. |
| `stellar-admin-theme` | Write a [theme file](/docs/ui/theming) from a description, your brand colors or a look you want to match. |

You install the skills with [Vercel's skills installer](https://github.com/vercel-labs/skills). The source of the skills is in the [StellarAdmin repository](https://github.com/stellar-admin/stellar-admin/tree/master/skills).

## Installing the skills

You need Node.js and Git. Run the following commands in your app's project directory:

```bash
npx skills add stellar-admin/stellar-admin --skill stellar-admin-ui
npx skills add stellar-admin/stellar-admin --skill stellar-admin-theme
```

The `--skill` option installs only the named skill. Without it, the installer lists all the StellarAdmin skills, including the ones for the [admin panel](/docs/admin/agent-skills).

The installer asks which agent to install the skills for. To skip the question, add `--agent claude-code` or `--agent codex`. The skills are installed in the project. To make them available in all your projects, add `--global`.

After installing, start a new agent session so that the agent loads the skills.

<Callout type="info">
  The skills only teach your agent how to use StellarAdmin.UI. Installing them doesn't install the NuGet package or change your app.
</Callout>

## Installing StellarAdmin.UI with the skill

Ask your agent to install StellarAdmin.UI:

> Use the stellar-admin-ui skill to install StellarAdmin.UI in this app.

Unless you've already said which one you want, the agent asks you to choose how much to change:

| Choice | What the agent does |
| --- | --- |
| **Basic installation** | Installs the package, registers the services and the Tag Helpers, and adds the stylesheet and the script. Your layout and Bootstrap stay as they are. |
| **Layout conversion** | Also converts your default layout to StellarAdmin.UI, and removes Bootstrap where nothing uses it any more. |

<Callout type="info">
  The basic installation keeps Bootstrap, which can conflict with the StellarAdmin.UI styles. Some of your existing pages may look different after you add the stylesheet.
</Callout>

## Building pages with the skill

Ask your agent for the page you want, and name the skill:

> Use the stellar-admin-ui skill to build a form for editing a booking.

Depending on your agent and the task, the agent may also use the skill without you naming it.

## Creating a theme with the skill

Ask your agent for the look you want:

> Use the stellar-admin-theme skill to give this app a warm, editorial, dense theme with a green accent.

The agent writes the theme file, links it in your layout and loads its fonts. It also gives you a link to the [theme builder](/theme-builder), where you can preview the theme and adjust it.

## Versions

The skills follow the main branch of the StellarAdmin repository, so they can describe features that aren't in the package your app uses yet. They tell the agent to check which version your app uses before following their examples. Updating the skills doesn't update your packages.
