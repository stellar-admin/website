A [theme file](/docs/ui/theming#changing-the-theme) sets the theme variables below on `:root`, inside `@layer sa.theme`:

```css title="wwwroot/css/theme.css"
@layer sa.theme {
  :root {
    /* Your theme variables go here */
  }
}
```

Set only the theme variables you want to change. The [theme builder](/theme-builder) has a control for each theme variable, with the same range.

<Callout type="idea">
  The package also contains the list of theme variables as JSON, at `/_content/StellarAdmin.UI/stellar-admin.theme-variables.json`. Tools can read it to get the theme variables of the version your app uses.
</Callout>

## Color

You can write colors in any CSS color syntax. StellarAdmin.UI adjusts the accent's fills and text to meet the WCAG contrast ratio of 4.5:1, so the accent can be any lightness.

Some theme variables follow another theme variable, and have no default. Set them only when you want a different value in dark mode, or for the text on the accent.

## Space and type

The density changes the spacing and the size of the controls, but not the size of the text. To change the size of the text, set the type scale.

Each font theme variable is a list of fonts. End it with the system fonts, and load the web font in your layout, as described in [adding fonts](/docs/ui/theming#adding-fonts).
