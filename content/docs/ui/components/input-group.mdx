## Usage

Put the input (or textarea) and one or more addons inside `<sa-input-group>`. The `align` of each addon decides where it sits.

```razor
<sa-input-group>
    <!-- 1. Add inputs -->
    <sa-input-group-input/>
    <!-- or -->
    <sa-input-group-textarea/>
    <!-- 2. Add addons -->
    <sa-input-group-addon align="...">
        <!-- you can add text inside the addon... -->
        <sa-input-group-text>...</sa-input-group-text>
        <!-- ...or buttons -->
        <sa-input-group-button>...</sa-input-group-button>
    </sa-input-group-addon>
</sa-input-group>
```

## API Reference

### `<sa-input-group>`

Renders a `<div>` element with `role="group"` that wraps the input and its add-ons.

### `<sa-input-group-input>`

Renders an `<input>` element styled for use inside an input group.

Renders a `<textarea>` element styled for use inside an input group.

  type={{

### `<sa-input-group-addon>`

Renders a `<div>` element with `role="group"` that holds text, icons, or buttons alongside the input. Clicking the add-on, outside its buttons, focuses the group's input.

<TypeTable
  type={{

        "InputGroupAddonAlign.Start | InputGroupAddonAlign.End | InputGroupAddonAlign.Top | InputGroupAddonAlign.Bottom",
      default: "InputGroupAddonAlign.Start",
    },
  }}
/>

### `<sa-input-group-text>`

Renders a `<span>` element for displaying text inside an add-on.

### `<sa-input-group-button>`

Renders a `<button>` element sized for use inside an add-on. The button doesn't submit its form unless it has `type="submit"`.
