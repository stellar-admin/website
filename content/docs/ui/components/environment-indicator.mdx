## Usage

Add one of the three indicators to your layout: `<sa-environment-stripe>`, a thin bar across the top of the window with the name of the environment on a tab, as above; `<sa-environment-frame>`; or `<sa-environment-banner>`. Each is fixed to the window, so it can go anywhere in the page. Render it only in the environments that should show one, however your application determines its environment.

```razor
@if (environmentName is not null)
{
    <sa-environment-stripe label="@environmentName" color="EnvironmentStripeColor.Warning" />
}
```

The text on the indicator is white or dark, whichever reads better on its color.

## API Reference

### `<sa-environment-stripe>`

Renders a `<div>` element fixed to the top of the window, forwarding any [global attributes](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes).

<TypeTable
  type={{
    label: {
      description: "The name of the environment.",
      type: "string",
      required: true,
    },
    color: {
      description: "The color of the indicator.",
      type: "EnvironmentStripeColor",
      typeDescription:
        "EnvironmentStripeColor.Neutral | EnvironmentStripeColor.Info | EnvironmentStripeColor.Success | EnvironmentStripeColor.Warning | EnvironmentStripeColor.Danger",
      default: "EnvironmentStripeColor.Neutral",
    },
    "custom-color": {
      description: "A CSS color that overrides color.",
      type: "string",
    },
    "custom-dark-color": {
      description: "A CSS color used in dark mode. Without it, custom-color is used in dark mode too.",
      type: "string",
    },
    "tab-size": {
      description: "The size of the tab that names the environment.",
      type: "EnvironmentStripeTabSize",
      typeDescription:
        "EnvironmentStripeTabSize.Small | EnvironmentStripeTabSize.Medium | EnvironmentStripeTabSize.Large | EnvironmentStripeTabSize.ExtraLarge",
      default: "EnvironmentStripeTabSize.Medium",
    },
  }}
/>
