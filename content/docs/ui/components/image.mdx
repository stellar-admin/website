## Usage

`<sa-image>` is a self-closing tag. Give it the image's URL in `src` and a description in `alt`.

```razor
<sa-image src="..." alt="..." />
```

Images are thumbnails by default: a small square, the size of a list item's media or a table cell. Set `variant` to `ImageVariant.Figure` for a record's main image, such as on its details page.

## Examples

### Sizes

Set `size` to `ImageSize.ExtraSmall`, `Small`, `Medium` or `Large`. A thumbnail is 24, 32, 40 or 64 pixels tall, and `Small` is the default, which fits a table row.

<Demo src="/demo/ui/image-sizes.html">
  <include>./_include/image-sizes.mdx</include>
</Demo>

### Aspect ratio

Set `aspect-ratio` to `ImageAspectRatio.Square`, `Landscape` (4:3), `Widescreen` (16:9) or `Portrait` (3:4) to choose the box's shape; `size` sets its height. By default the image covers the box and its edges are cropped. Set `fit` to `ImageFit.Contain` to show the whole image inside the box on a quiet backdrop instead, as the last image here does. `ImageAspectRatio.Original` keeps the image's own shape.

<Demo src="/demo/ui/image-aspect-ratio.html">
  <include>./_include/image-aspect-ratio.mdx</include>
</Demo>

### Figure

A figure keeps the image's own shape by default and grows to the width of its container, up to a maximum height that `size` sets: 8, 10, 15 or 20rem, with `Medium` as the default. Corners follow the theme's radius for boxes. A figure without an image reads "No image", so it suits a details page where every record has the same layout.

### Interaction

An image with a `src` is a button that opens the image larger in a dialog, which closes with its close button, Escape or a click outside. The first image of a page that can open it writes the dialog's template, so a page with many images still has one dialog. Set `interaction` to `ImageInteraction.Preview` to show the larger image beside the thumbnail on hover instead, or to `ImageInteraction.None` for an image that does neither.

<Demo src="/demo/ui/image-interaction.html">
  <include>./_include/image-interaction.mdx</include>
</Demo>

The button is named by `alt`, so always describe the image; without `alt` it is named "View image".

### Empty and broken images

Without a `src` the image shows a placeholder, and an image that fails to load shows a broken-image tile in its place, which the script sets from the image's `error` event. A figure adds a short message to either. The tile replaces the button, so a broken image cannot open an empty dialog.

## API Reference

### `<sa-image>`

Renders a `<button>` element for an image that opens a dialog, and a `<span>` element otherwise, holding an `<img>` and the placeholder and broken-image fallbacks, forwarding any [global attributes](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes).
