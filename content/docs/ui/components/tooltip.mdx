## Usage

`<sa-tooltip>` uses the [Interest Invokers](https://developer.mozilla.org/en-US/docs/Web/API/Popover_API/Using_interest_invokers) and [Popover](https://developer.mozilla.org/en-US/docs/Web/API/Popover_API/Using) APIs to display a tooltip for UI elements.

<Callout type="warn">
  The Interest Invokers API is still experimental. See the Limitations below.
</Callout>

```razor
<!-- Add the element to trigger the tooltip and specify the ID of
     the tooltip to trigger using the interestfor attribute -->
<sa-button interestfor="--example-tooltip">
    Tooltip trigger
</sa-button>
<!-- Add the tooltip and specify its id attribute -->
<sa-tooltip id="--example-tooltip">
    <!-- Add the text to display inside the tooltip -->
</sa-tooltip>
```

### Limitations

1. The Interest Invokers API is [not supported across all browsers](https://caniuse.com/wf-interest-invokers) yet. StellarAdmin includes the [mfreed7/interestfor](https://github.com/mfreed7/interestfor) polyfill to ensure it works across all browsers. Make sure you have included the StellarAdmin JavaScript file in your pages.
2. The Interest Invokers API supports only the `<a>`, `<button>` and `<area>` elements as invoker elements (the element that triggers the tooltip). StellarAdmin's JavaScript handles `interestfor` on other elements too, such as inputs, selects, textareas and toggles, with the same delays and events. See [Supported Tag Helpers](#supported-tag-helpers) below for the Tag Helpers you can use.

We strongly recommend you [read about the Interest Invokers API on MDN](https://developer.mozilla.org/en-US/docs/Web/API/Popover_API/Using_interest_invokers#creating_an_interest_invoker) to familiarize yourself with its use and limitations.

## Examples

### Position

Control the position of the tooltip relative to the trigger element using the `side` and `align` attributes. `side` sets the side of the trigger the tooltip appears on and defaults to `TooltipSide.Top`. `align` sets how the tooltip lines up with the trigger along that side and defaults to `TooltipAlign.Center`.

You can add a delay before opening and closing the tooltip by using the `interest-delay-start` and `interest-delay-end` CSS properties.

### JavaScript API

Since `<sa-tooltip>` uses the [Popover API](https://developer.mozilla.org/en-US/docs/Web/API/Popover_API/Using), you can use the `showPopover()`, `hidePopover()` and `togglePopover()` methods to control visibility of the popover.

When using the JavaScript API, you also need to make sure you specify the `source` element to ensure the tooltip is aligned correctly with the UI element for which the tooltip is shown.

<Callout type="tip">
  The `togglePopover()` method does not work correctly on Chromium browsers when you use the `popover="hint"` attribute - which is the default value `<sa-tooltip>` uses. If you want to use `togglePopover()` on Chromium, you must override this attribute by setting it to `manual`, as you can see in the example below.
</Callout>

## Accessibility

`<sa-tooltip>` renders a hint popover that the trigger shows through its `interestfor` attribute. The browser, or the bundled polyfill, shows it when the trigger is hovered or receives keyboard focus and hides it on Escape, so the tooltip is reachable without a mouse as long as the trigger itself is focusable.

Keep the tooltip text supplemental. It does not become the trigger's accessible name, so an icon-only trigger still needs its own `aria-label`.

## API Reference

### `<sa-tooltip>`

Renders a `<div>` element with `popover="hint"` (which you can override by supplying your own `popover` attribute), shown by an invoker element whose `interestfor` attribute references the tooltip's `id`.
