## Usage

Use `<sa-avatar>` to display a single avatar. Display a group of avatars using `<sa-avatar-group>`.

```razor
<!-- Display a single avatar -->
<sa-avatar src="..." />

<!-- Display a group of avatars -->
<sa-avatar-group>
    <sa-avatar src="..." />
    <sa-avatar src="..." />
</sa-avatar-group>
```

## API Reference

### `<sa-avatar>`

Renders a `<span>` element containing either an `<img>` (when `src` is set) or a fallback `<span>` with the initials.

<TypeTable

      type: "string",

    name: {
      description:
        "The user's name. Used as the image's alt text and, without an image or initials, to derive the initials from the first letters of the first two words (or the first two letters of a single word).",

    size: {
      description: "The size of the avatar.",

    },
    src: {
      description: "The URL of the avatar image. Without it, the avatar shows initials.",
      type: "string",
    },
  }}
/>

### `<sa-avatar-badge>`

Renders a `<span>` element positioned in the bottom-right corner of the parent avatar, sized to match the avatar's `size`.

### `<sa-avatar-group>`

Renders a `<div>` element that overlaps its child avatars.

### `<sa-avatar-group-count>`

Renders a `<div>` element displaying its child content (such as `+3`) at the end of an avatar group.
