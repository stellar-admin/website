## Usage

Set `value` and optionally add a label and an `<sa-progress-value>` readout.

```razor
<sa-progress value="...">
    <sa-progress-label>...</sa-progress-label>
    <sa-progress-value/>
</sa-progress>
```

## API Reference

### `<sa-progress>`

Renders a `<div>` element containing the progress track and indicator.

<TypeTable
  type={{
    max: {
      description:
        "The value at which the task is complete. Must be greater than `min`.",
      type: "double",
      default: "100",
    },
    min: {
      description:
        "The value at which the task has not started. Must be less than `max`.",
      type: "double",
      default: "0",
    },
    value: {
      description:
        "The current progress. Must be from `min` to `max`.",
      type: "double",
      default: "0",
    },
  }}
/>

### `<sa-progress-label>`

Renders a `<span>` element containing the label text.

### `<sa-progress-value>`

Renders a `<span>` element. When it has no content, it displays the percentage completed, calculated from the parent `<sa-progress>` values.
