## Usage

Wrap fields in `<sa-grid>` and set `columns` to the number of columns. Each field takes one column unless it sets its own span with `column-span`.

```razor
<sa-grid columns="2">
    <sa-input asp-for="FirstName" />
    <sa-input asp-for="LastName" />
    <sa-input asp-for="Email" column-span="full" />
</sa-grid>
```

The columns respond to the width of the grid rather than the viewport, so the same markup works in a page, a card or a side panel. `columns` applies once the grid is at least 40rem wide, and the grid uses one column below that.

Fields carry their own span: `<sa-field>`, every input that renders its own field, such as `<sa-input asp-for="...">` or `<sa-select asp-for="...">`, and `<sa-display-field>` accept the `column-span` and `column-start` attributes. Wrap anything else, such as a [Form Section](./form-section) or a [Details](./details) list, in `<sa-grid-item>` to give it a span or a start.

## Examples

### Columns and spans

Use `columns-base`, `columns-sm`, `columns-md` and `columns-lg` to set the number of columns at the smallest width, 30rem, 40rem and 56rem; a width without a value uses the value of the next smaller width.

Set `column-span` to a number from 1 to 12, or to `full` to span every column. `column-span-sm`, `column-span-md` and `column-span-lg` set the span at each width in the same way. A width without a span uses the span of the next smaller width, and a span is limited to the number of columns at each width.

### Column start

Set `column-start` to the column a field starts at, from 1 to 12, to begin a new row or leave a gap. In this example the dates start a new row and the phone number leaves the first column empty. `column-start-sm`, `column-start-md` and `column-start-lg` set the start at each width, and `auto` places the field after the one before it again. A width without a start uses the start of the next smaller width. The start is ignored where the grid has one column or the field would extend past the last column, so the fields stack in a narrow grid.

### Field spans and starts

`<sa-field>`, every input that renders its own field and `<sa-display-field>` accept the same `column-span`, `column-span-sm`, `column-span-md`, `column-span-lg`, `column-start`, `column-start-sm`, `column-start-md` and `column-start-lg` attributes. They apply when the field is a direct child of `<sa-grid>` or `<sa-details>` and are ignored elsewhere. An invalid value throws an exception when the page renders.
