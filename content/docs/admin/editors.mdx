---
title: Choosing an editor
description: How fields pick their input, and how to pick another
---

Every field gets an editor from its type and attributes. Most of the time you don't need to choose one.

| Property | Editor |
| --- | --- |
| `string`, `Guid` | Text input. `[EmailAddress]`, `[Phone]`, `[Url]` or `[DataType]` pick email, tel, url or password. |
| Numbers | Number input |
| `[DataType(DataType.MultilineText)]` | Textarea |
| `[DataType(DataType.Html)]` | Rich text editor |
| `DateOnly`, `DateTime`, `TimeOnly` | Date, date and time, or time input |
| `bool` | Checkbox |
| `bool?` | Select with Yes, No and Not set |
| Enum | Select of its members |
| `List<string>`, `int[]` and other lists of text or numbers | List editor |
| `Dictionary<string, string>` and other simple dictionaries | Dictionary editor |
| Foreign key to a resource (EF Core) | Lookup |
| Many-to-many navigation to a resource (EF Core) | Multi-lookup |

One gotcha: a `string` without `[DataType]` is a single-line input, however long it gets. Give descriptions, bios and notes a textarea.

## Picking another editor

Each editor has its own method on the field. Pass a callback to change its settings:

```cs
fields.Add(trip => trip.Summary).UseTextareaEditor(textarea => textarea.Rows = 4);
fields.Add(trip => trip.IsPublished).UseToggleEditor();
fields.Add(trip => trip.Difficulty).UseSegmentedControlEditor();
fields.Add(trip => trip.MaxGroupSize).UseSliderEditor(slider =>
{
    slider.Min = 2;
    slider.Max = 16;
    slider.ValueFormat = "{0} people";
});
```

Settings you don't set come from the property where possible. A slider takes its range from `[Range]`, for example.

## Extra CSS classes

Every editor has `ClassNames`, for adding classes from your own stylesheet to its parts, such as `Control`, `Label` and `Description`:

```cs
fields.Add(trip => trip.Summary).UseTextareaEditor(textarea => textarea.ClassNames.Control = "trip-summary");
```

The panel's stylesheet only has the classes its own components use, so Tailwind utilities won't work here unless you [add a stylesheet](/docs/admin/theming) that has them.
