title: Overview
description: How StellarAdmin chooses a field's editor, and how to choose another
---

A field's *editor* is the control people use to enter the field's value, such as a text input or a checkbox. StellarAdmin chooses each field's editor from the property's type and attributes, so most fields don't need you to choose one. The table below lists the editor StellarAdmin chooses for each kind of property:

| Property | Editor |
| --- | --- |
| `string`, `Guid` | Text input |
| `string` with `[EmailAddress]`, `[Phone]`, `[Url]` or `[DataType(DataType.Password)]` | Email, phone, URL or password input |
| `string` with `[DataType(DataType.MultilineText)]` | Textarea |
| `string` with `[DataType(DataType.Html)]` | Rich text editor |
| Numbers | Number input |
| `DateOnly`, `DateTime`, `TimeOnly` | Date, date and time, or time input |
| `DateTimeOffset` | Text input that keeps the offset |
| `bool` | Checkbox |
| `bool?` | Select with Yes, No and Not set |
| Enum | Select of the enum's members |
| Enum with `[Flags]` | Text input |
| List of strings or numbers, such as `List<string>` or `int[]` | List editor |
| Dictionary with a string or enum key, and a string, number or enum value | Dictionary editor |
| Foreign key to a registered resource (EF Core) | Lookup |
| Many-to-many navigation to a registered resource (EF Core) | Multi-lookup |

A `string` without `[DataType(DataType.MultilineText)]` is a single-line text input, however long the text is. For longer text, such as a description or notes, add the attribute, or choose a textarea.

## Choosing another editor

To choose another editor, call the editor's method on the field. To change the editor's settings, pass a callback. The example below uses a textarea for the summary, a switch for `IsPublished`, and a slider for the group size:

```cs
fields.Add(trip => trip.Summary).UseTextareaEditor(textarea => textarea.Rows = 4);
fields.Add(trip => trip.IsPublished).UseToggleEditor();
fields.Add(trip => trip.MaxGroupSize).UseSliderEditor(slider =>
{
    slider.Min = 2;
    slider.Max = 16;
    slider.ValueFormat = "{0} people";
});
```

A setting you leave unset comes from the property where possible, such as a slider's range from `[Range]`. Each editor's page lists its settings and their defaults:

| Editor | Method | Page |
| --- | --- | --- |
| Text input | `UseTextInputEditor()` | [Inputs](/docs/admin/inputs#entering-text-and-numbers) |
| Textarea | `UseTextareaEditor()` | [Inputs](/docs/admin/inputs#entering-long-text) |
| Date, date and time, time | `UseDateInputEditor()`, `UseDateTimeInputEditor()`, `UseTimeInputEditor()` | [Inputs](/docs/admin/inputs#entering-dates-and-times) |
| Checkbox, switch | `UseCheckboxEditor()`, `UseToggleEditor()` | [Inputs](/docs/admin/inputs#entering-yes-or-no) |
| Slider | `UseSliderEditor()` | [Inputs](/docs/admin/inputs#choosing-a-number-with-a-slider) |
| One-time code | `UseOneTimeCodeEditor()` | [Inputs](/docs/admin/inputs#entering-a-code) |
| Select, radio group, segmented control | `UseSelectEditor()`, `UseRadioGroupEditor()`, `UseSegmentedControlEditor()` | [Choices](/docs/admin/choice-editors) |
| Checkbox group, toggle group | `UseCheckboxGroupEditor()`, `UseToggleGroupEditor()` | [Choices](/docs/admin/choice-editors) |
| List, dictionary | `UseListEditor()`, `UseDictionaryEditor()` | [Lists and dictionaries](/docs/admin/list-and-dictionary-editors) |
| Lookup, multi-lookup | `UseLookupSheetEditor()`, `UseMultiLookupSheetEditor()` | [Foreign keys](/docs/admin/foreign-keys), [many-to-many](/docs/admin/many-to-many) |
| Image | `UseImageEditor()` | [Images](/docs/admin/image-editor) |
| Rich text | `UseRichTextEditor()` | [Rich text](/docs/admin/rich-text-editor) |
| Icon | `UseIconEditor()` | [Icons](/docs/admin/icon-editor) |

If the editor can't edit the property, such as a checkbox for a `string`, StellarAdmin uses the property's default editor instead, and reports a [configuration problem](/docs/admin/configuration-problems).

For an editor StellarAdmin doesn't have, such as a color picker, write a [custom editor](/docs/admin/custom-editors). StellarAdmin has no editor for uploading files, other than the [image editor](/docs/admin/image-editor).

## Adding CSS classes

To style one field differently from the rest of the form, such as a code in a monospace font, add your own CSS classes to its editor. Every editor has a `ClassNames` property for adding CSS classes to the editor's parts: `Root`, `Content`, `Label`, `Control`, `Description` and `Error`. Some editors have more parts, such as a slider's `Mark`. The example below adds a class to the textarea of the trip's summary:

```cs
fields.Add(trip => trip.Summary).UseTextareaEditor(textarea =>
{
    textarea.ClassNames.Control = "trip-summary";
});
```

StellarAdmin's stylesheet contains only the classes its own components use, so a Tailwind utility class works only if you [add a stylesheet](/docs/admin/theming) that contains it.
