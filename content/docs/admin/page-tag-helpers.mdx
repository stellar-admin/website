---
title: Page Tag Helpers and slots
description: Add your own content inside a page of the admin panel
---

StellarAdmin renders the content of each resource page with a Tag Helper. When you [override a page](/docs/admin/overriding-pages), your view uses the Tag Helper for the page, and passes it the view's model:

| Tag Helper | Page | Model |
| --- | --- | --- |
| `<sa-index-page>` | Index | `ResourceIndexPageViewModel<TResource>` or `IResourceIndexPageViewModel` |
| `<sa-form-page>` | Create and edit | `ResourceFormPageViewModel` |
| `<sa-view-page>` | View | `ResourceViewPageViewModel` |

```razor title="Areas/StellarAdmin/Views/bookings/View.cshtml"
@model ResourceViewPageViewModel
@{
    ViewData["Title"] = Model.Title;
}

<sa-view-page model="Model" />
```

## Adding content with slots [#slots]

A *slot* is a place inside the page where you can add your own content, such as a button in the page's header. To fill a slot, put an `<sa-slot-content>` element with the slot's name inside the Tag Helper.

The example below adds an **Invoice** button after the **Edit** button of the bookings view page, and a card below the fields:

```razor title="Areas/StellarAdmin/Views/bookings/View.cshtml"
@model ResourceViewPageViewModel
@{
    ViewData["Title"] = Model.Title;
}

<sa-view-page model="Model">
    <sa-slot-content name="post-page-actions">
        <sa-button-link href="@($"/invoices/{Model.EntityId}")" variant="ButtonVariant.Outline">
            Invoice
        </sa-button-link>
    </sa-slot-content>
    <sa-slot-content name="post-view-fields">
        <sa-card>
            <sa-card-content>Payment history goes here.</sa-card-content>
        </sa-card>
    </sa-slot-content>
</sa-view-page>
```

<Callout type="info">
The Tag Helper renders only the content of its `<sa-slot-content>` elements. Anything else you put inside it isn't rendered. To add content outside the slots, put it before or after the Tag Helper.
</Callout>

Each Tag Helper has the following slots:

| Tag Helper | Slot | Where the content goes |
| --- | --- | --- |
| `<sa-index-page>` | `pre-page-actions` | In the header, before the **Create** button |
| | `post-page-actions` | In the header, after the **Create** button |
| `<sa-form-page>` | `pre-form-fields` | Above the fields |
| | `post-form-fields` | Below the fields |
| | `form-leading-actions` | At the start of the buttons below the form |
| | `pre-form-actions` | Before the **Cancel** button |
| | `post-form-actions` | After the submit button |
| `<sa-view-page>` | `pre-page-actions` | In the header, before the **Back** button |
| | `post-page-actions` | In the header, after the **Edit** button |
| | `pre-view-fields` | Above the fields |
| | `post-view-fields` | Below the fields |

StellarAdmin's own edit view puts the **Delete** button in `form-leading-actions`. If you override the edit page, see [keeping the Delete button](/docs/admin/overriding-pages#keeping-the-delete-button-on-the-edit-page).

The index page has no slot between its header and the grid. To add content there, put it above the Tag Helper, as in the example on [overriding pages](/docs/admin/overriding-pages#adding-content-to-a-page).

## Replacing the content of the page

To replace the content that a Tag Helper renders, set its `view` attribute to the name of your own partial view, or to its path from your app's root. The partial view receives the Tag Helper's model, and renders the content of a slot where it contains an `<sa-slot-outlet>` element with the slot's name:

```razor
<sa-slot-outlet name="post-page-actions" />
```
