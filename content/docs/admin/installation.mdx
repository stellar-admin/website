To install StellarAdmin, you need an ASP.NET Core app (MVC, Razor Pages or minimal APIs) running on .NET 10 or later.

<Steps>
    <Step>
        ### Install the packages

        Add the `StellarAdmin` package:

        <Tabs items={['.NET CLI', 'Package Manager']}>
            <Tab>
                ```text
                dotnet add package StellarAdmin
                ```
            </Tab>
            <Tab>
                ```text
                Install-Package StellarAdmin
                ```
            </Tab>
        </Tabs>

        If you want to use StellarAdmin with EF Core, also add the `StellarAdmin.EntityFrameworkCore` package:

        <Tabs items={['.NET CLI', 'Package Manager']}>
            <Tab>
                ```text
                dotnet add package StellarAdmin.EntityFrameworkCore
                ```
            </Tab>
            <Tab>
                ```text
                Install-Package StellarAdmin.EntityFrameworkCore
                ```
            </Tab>
        </Tabs>
    </Step>
    <Step>
        ### Register StellarAdmin

        Call `AddStellarAdmin` in `Program.cs` to register the StellarAdmin services.

        ```cs
        using StellarAdmin;

        builder.Services.AddStellarAdmin(admin =>
        {
            // Resources and other configuration go here
        });
        ```
    </Step>
    <Step>
        ### Map StellarAdmin

        Call `MapStellarAdmin` to map the StellarAdmin endpoints. StellarAdmin's CSS and scripts are static assets, so your app also needs to serve those. If it doesn't already call `MapStaticAssets` or `UseStaticFiles`, add a call to `MapStaticAssets`:

        ```cs
        var app = builder.Build();

        app.MapStaticAssets();
        app.MapStellarAdmin();

        app.Run();
        ```
    </Step>
    <Step>
        ### Open the admin panel

        Run the application and go to `/stellaradmin`. You will see the admin panel layout with a setup checklist that will help you get started with StellarAdmin.

        <Screenshot name="home-page-setup-checklist" alt="The setup checklist on the admin panel's home page" />
    </Step>
</Steps>

## Changing the path

The admin panel is served at `/stellaradmin`. To serve it on another path, pass the path to `MapStellarAdmin()`:

```cs
app.MapStellarAdmin("/admin");
```

## Requiring authorization

By default, anyone who can reach your app can open the admin panel. To restrict access, call `RequireAuthorization`.

```cs
builder.Services.AddStellarAdmin(admin =>
{
    admin.RequireAuthorization();
});
```

StellarAdmin plugs in to the standard ASP.NET Core authentication and authorization. See [authorization](/docs/admin/authorization) for other options.
