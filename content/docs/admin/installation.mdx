To install StellarAdmin, you need an ASP.NET Core app (MVC, Razor Pages or minimal APIs) running on .NET 10 or later.

<Steps>
    <Step>
        ### Install the packages

        Add the `StellarAdmin` package:

        <Tabs items={['.NET CLI', 'Package Manager']}>
            <Tab>
                ```text
                dotnet add package StellarAdmin
                ```
            </Tab>
            <Tab>
                ```text
                Install-Package StellarAdmin
                ```
            </Tab>
        </Tabs>

        If you want to use StellarAdmin with EF Core, also add the `StellarAdmin.EntityFrameworkCore` package:

        <Tabs items={['.NET CLI', 'Package Manager']}>
            <Tab>
                ```text
                dotnet add package StellarAdmin.EntityFrameworkCore
                ```
            </Tab>
            <Tab>
                ```text
                Install-Package StellarAdmin.EntityFrameworkCore
                ```
            </Tab>
        </Tabs>

        <Callout type="idea">
            `StellarAdmin` also installs [StellarAdmin.UI](/docs/ui), the Tag Helper library StellarAdmin is built with. You can also use its components in your app's own pages to have a consistent look and feel.
        </Callout>
    </Step>
    <Step>
        ### Register StellarAdmin

        Call `AddStellarAdmin` in `Program.cs` to register the services StellarAdmin needs.

        ```cs
        using StellarAdmin;

        builder.Services.AddStellarAdmin(admin =>
        {
            // Resources and other configuration go here
        });
        ```
    </Step>
    <Step>
        ### Map StellarAdmin

        Call `MapStellarAdmin` after `builder.Build()`. StellarAdmin's CSS and scripts are static assets, so your app also needs to serve those. If it doesn't already call `MapStaticAssets` or `UseStaticFiles`, add `MapStaticAssets`:

        ```cs
        var app = builder.Build();

        app.MapStaticAssets();
        app.MapStellarAdmin();

        app.Run();
        ```

        `MapStellarAdmin` can go before or after your app's own endpoints.
    </Step>
    <Step>
        ### Open the admin panel

        Run the application and go to `/stellaradmin`. The sidebar has no resources yet, because you haven't added any. In Development, the admin panel's home page lists the setup steps you haven't done.

        <ThemedImage light="/images/admin/generated/home-page-setup-checklist.png" dark="/images/admin/generated/home-page-setup-checklist-dark.png" alt="The setup checklist on the admin panel's home page" width={1280} height={800} />
    </Step>
</Steps>

## Changing the path

The admin panel is served at `/stellaradmin`. To serve it at another path, pass the path to `MapStellarAdmin`:

```cs
app.MapStellarAdmin("/admin");
```

## Requiring authorization

By default, anyone who can reach your app can open the admin panel. To restrict it, call `RequireAuthorization`. This example only allows users in the Staff role:

```cs
builder.Services.AddStellarAdmin(admin =>
{
    admin.RequireAuthorization(policy => policy.RequireRole("Staff"));
});
```

This uses your app's existing authentication. See [authorization](/docs/admin/authorization) for other options.
