StellarAdmin has two skills that teach coding agents, such as Claude Code and Codex, how to use it:

| Skill | Description |
| --- | --- |
| `stellar-admin-setup` | Teaches your agent how to install StellarAdmin in your app: add the packages, call `AddStellarAdmin()` and `MapStellarAdmin()`, and check that the admin panel works. The agent also prompts you whether you want to define resources, configure authorization, or configure branding. |
| `stellar-admin` | Teaches your agent how to build an app using StellarAdmin: how to define resources, index pages, forms, editors, and relationships. It also covers topics such as customizing the sidebar, configuring authorization, and more. This is the skill you will use the most often. |

Install the skills using [Vercel's skills installer](https://github.com/vercel-labs/skills). The source of the skills is in the [StellarAdmin repository](https://github.com/stellar-admin/stellar-admin/tree/master/skills).

## Installing the skills

<Callout>
  The installer requires Node.js and Git, so ensure you have those installed before running the installer.
</Callout>

Install the skills by running the following commands in your app's project directory:

```bash
npx skills add stellar-admin/stellar-admin --skill stellar-admin-setup
npx skills add stellar-admin/stellar-admin --skill stellar-admin
```

The `--skill` option installs only the specified skill. Without it, the installer lists all the StellarAdmin skills, including the ones for [StellarAdmin.UI](/docs/ui/agent-skills), and allow you to pick the ones you want to install. The installer prompts you which agent(s) to install the skills for. You can specify these via the commandline using the `--agent` flag, for example `--agent claude-code`. 

After installing, start a new agent session so that the agent loads the skills.

## Using the skills

You can ask your agent to install StellarAdmin:

> Use the stellar-admin-setup skill to add StellarAdmin to this app.

Then ask it to build the admin panel:

> Add bookings to the admin panel, with search on the reference and Pending and Confirmed tabs.

## Versions

The skills follow the main branch of the StellarAdmin repository, so they can describe features that aren't in the packages your app uses yet.
