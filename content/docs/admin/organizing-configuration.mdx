---
title: Organizing configuration
description: Keep Program.cs small as your admin panel grows
---

Once you have more than a few resources, configuring them all in `Program.cs` makes the file hard to read. Move each resource into an extension method in its own file, and keep only the settings for the whole admin panel in `Program.cs`.

The example below calls a single `AddResources()` method from `Program.cs`:

```cs
// Program.cs
builder.Services.AddStellarAdmin(admin =>
{
    admin.RequireAuthorization(policy => policy.RequireRole("Staff"));
    admin.ConfigureBranding(branding => branding.Title = "Voyager Travel");
    admin.AddResources();
});
```

`AddResources()` is an extension method on `StellarAdminBuilder`, defined in the `AdminResources` class. It calls the extension method for each resource:

```cs
// Admin/AdminResources.cs
public static class AdminResources
{
    public static StellarAdminBuilder AddResources(this StellarAdminBuilder admin) =>
        admin.AddGuides().AddTrips().AddBookings();
}
```

Each resource's extension method is defined in its own class, and registers and configures that resource. The example below defines `AddGuides()` in the `GuidesAdmin` class:

```cs
// Admin/GuidesAdmin.cs
using StellarAdmin;
using StellarAdmin.EntityFrameworkCore;

public static class GuidesAdmin
{
    public static StellarAdminBuilder AddGuides(this StellarAdminBuilder admin) =>
        admin.AddEfCoreResource<Guide>(resource =>
        {
            resource.SidebarItem(item => item.Group = "Operations");
            resource.Index(index => index.Columns(columns => columns.Add(guide => guide.Name)));
        });
}
```

## Ordering the sidebar

Resources appear in the sidebar in the order you register them, unless you set their `Order`. In the example above, the order of the calls in `AddResources()` is the order of the sidebar. See [ordering the sidebar](/docs/admin/sidebar#ordering-the-sidebar) for groups and ordering.

## Sharing fields

When the create and edit forms have the same fields, add the fields in a method that takes a `ResourceFieldsBuilder<TResource>`, and pass the method to both `Fields()` calls.

```cs
using StellarAdmin.Resources.Builders;

static void GuideFields(ResourceFieldsBuilder<Guide> fields)
{
    fields.Add(guide => guide.Name);
    fields.Add(guide => guide.Email);
}

resource.AllowCreate(create => create.Fields(GuideFields));
resource.AllowEdit(edit => edit.Fields(GuideFields));
```
