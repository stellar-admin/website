To configure the admin panel's name and logo, call `ConfigureBranding()`. These are displayed at the top of the sidebar:

```cs
using StellarAdmin.Sidebar;

admin.ConfigureBranding(branding =>
{
    branding.Title = "Voyager Travel";
    branding.Subtitle = "Admin";
    branding.Logo = BrandingLogo.Icon("compass");
});
```

The branding builder has the following members:

| Member | Description |
| --- | --- |
| `Title` | Sets the admin panel's name. The default is derived from your app's name, for example, an app named `Voyager.Admin` will result in the name "Voyager Admin". |
| `Subtitle` | Sets a second line under the title. The default is none. |
| `Logo` | Sets the logo. The default is none, which displays the title on its own. |
| `Href` | Sets the URL that the title and logo link to: an absolute URL, or a path in your app that starts with `~/`. The default is the admin panel's [home page](/docs/admin/home-page). |

The browser tab also displays the title after the page's name, such as "Bookings - Voyager Travel".

## Choosing a logo

To set the logo, set `Logo` to one of the following:

| Logo Type | Description |
| --- | --- |
| `BrandingLogo.Icon(name)` | Displays an [icon](/docs/ui/icons) in a colored tile, beside the title. |
| `BrandingLogo.Image(path)` | Displays a square image beside the title. |
| `BrandingLogo.Wordmark(path)` | Displays an image in place of the title and the subtitle, with the title as its alt text. |

<Screenshot name="branding-logo" alt="The top of the sidebar with each kind of logo" variants={["No logo", "Icon", "Image", "Wordmark"]} todo="Sidebar header crops of title Voyager Travel and subtitle Admin with no logo, an icon and an image, and of a wordmark." />

The path is an absolute URL, or a path in your app that starts with `~/`. You can specify an second image to be displayed in dark mode by passing it as the `darkPath` parameter of `Image()` or `Wordmark()`:

```cs
branding.Logo = BrandingLogo.Wordmark("~/img/wordmark.svg", "~/img/wordmark-dark.svg");
```

### Placing a wordmark

StellarAdmin centers a wordmark, at the height of the title and the subtitle it replaces. To change the layout and placement, pass a `WordmarkLayout` as the last argument of `Wordmark()`. The example below stretches a wide wordmark across the sidebar, so it doesn't look small:

```cs
branding.Logo = BrandingLogo.Wordmark("~/img/wordmark.svg", WordmarkLayout.Fill);
```

The layout can be one of the following:

| Layout | Description |
| --- | --- |
| `WordmarkLayout.Center` | Centers the wordmark. This is the default. |
| `WordmarkLayout.Start` | Lines the wordmark up with the sidebar items. |
| `WordmarkLayout.Fill` | Stretches the wordmark across the sidebar, up to twice its height. |

## Replacing the top of the sidebar

When the settings can't produce the design you want, add your own `Areas/StellarAdmin/Views/Shared/_SidebarBrand.cshtml` to your app, which replaces StellarAdmin's. The view's model is a `SidebarBrandModel`, with the `Title`, `Subtitle`, `Logo` and `Href` you configured. The folder needs the [view imports](/docs/admin/overriding-pages#view-imports).
