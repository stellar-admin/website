A *display type* determines how a value is displayed on a resource's [view page](/docs/admin/view-pages), in a [display field](/docs/admin/fields#displaying-values-that-arent-edited), and in grids. StellarAdmin chooses each value's display type from the property's type and attributes as follows:

| Property | Display type |
| --- | --- |
| `string` | `TextDisplay` |
| `string` with `[EmailAddress]` | `EmailDisplay` |
| `string` with `[Phone]` | `PhoneDisplay` |
| `string` with `[Url]` | `LinkDisplay` |
| `string` with `[DataType(DataType.Html)]` | `HtmlDisplay` |
| Numbers | `NumberDisplay` |
| `DateOnly`, `DateTime`, `DateTimeOffset`, `TimeOnly` | `DateDisplay` |
| `bool` | `BooleanDisplay` |
| Enum | `EnumDisplay` |
| List of strings or numbers, such as `List<string>` or `int[]` | `BadgeDisplay` |
| Dictionary with a string or enum key, and a string, number or enum value | `BadgeDisplay` |

## Choosing another display type

To use another display type, call `UseDisplay()` on the column or the display field. To change the display type's settings, pass a callback function. The example below displays whether a traveller has opted in to marketing as text instead of an icon:

```cs
using StellarAdmin.Resources.Displays;

admin.AddEfCoreResource<Traveller>(resource =>
{
    resource.Index(index => index.Columns(columns =>
    {
        columns.Add(traveller => traveller.FirstName);
        columns.Add(traveller => traveller.LastName);
        columns.Add(traveller => traveller.Email);
        columns.Add(traveller => traveller.MarketingOptIn, column =>
            column.UseDisplay<BooleanDisplay>(flag =>
            {
                flag.Appearance = BooleanDisplayAppearance.Text;
                flag.TrueText = "Subscribed";
                flag.FalseText = "Not subscribed";
            }));
    }));
});
```

## Empty values

When a value is `null` or empty, StellarAdmin displays the column's or the field's `EmptyText`. If `EmptyText` isn't set, it uses the property's `[DisplayFormat(NullDisplayText)]`. Without either, the grid displays an empty cell, and a display field displays a dash.

`ImageDisplay` is the exception: it displays a placeholder for an empty value.
