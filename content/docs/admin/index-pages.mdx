Every resource has an *index page*, which lists the resource's records in a grid. A resource's index page is at `/stellaradmin/{slug}`, such as `/stellaradmin/bookings`.

To configure the grid, call `Index()` on the resource. The example below gives the bookings grid three columns, a search box, **All** and **Pending** scopes, a default sort and paging:

```cs
resource.Index(index =>
{
    index.Columns(columns =>
    {
        columns.Add(booking => booking.Reference);
        columns.Add(booking => booking.Customer);
        columns.Add(booking => booking.DepartureDate, column => column.Sortable());
    });
    index.EnableSearch(term => booking => booking.Reference.Contains(term));
    index.EnableScopes(scopes =>
    {
        scopes.Add("all", "All");
        scopes.Add("pending", "Pending", booking => booking.Status == BookingStatus.Pending);
        scopes.DefaultScope = "all";
    });
    index.DefaultSortBy(booking => booking.DepartureDate);
    index.EnablePaging();
});
```

You can read more about each of the grid's features on its own page:

- [Columns](/docs/admin/columns): choose the columns the grid displays.
- [Search](/docs/admin/search): add a search box that filters the records.
- [Scopes](/docs/admin/scopes): add tabs that filter the records, such as **All**, **Pending** and **Confirmed**.
- [Sorting and paging](/docs/admin/sorting-and-paging): let people sort the grid by a column, and split the records into pages.
- [Row details](/docs/admin/row-details): expand a row to display more about a record.
- [Inline editing](/docs/admin/inline-editing): edit and add records in the grid.

Searching, selecting a scope, sorting and paging update the grid without reloading the page. The grid keeps its search, scope, sort and page in the URL, so you can bookmark or share a filtered list. Changing the search or the scope returns the grid to the first page.

## Changing the title and labels

To change the index page's title, or the labels of its **Create** button and row actions, set these properties in the `Index()` callback:

| Property | Default |
| --- | --- |
| `Title` | The plural label, such as "Bookings" |
| `CreateLabel` | "Create" |
| `EditLabel` | "Edit" and the singular label, such as "Edit Booking" |
| `ViewLabel` | "View" and the singular label, such as "View Booking" |
| `DeleteLabel` | "Delete" and the singular label, such as "Delete Booking" |

The example below changes the title and the label of the **Create** button:

```cs
resource.Index(index =>
{
    index.Title = "All bookings";
    index.CreateLabel = "New booking";
});
```

To change the defaults for every resource, see [global labels](/docs/admin/global-labels). The labels of inline rows are on the [inline editing](/docs/admin/inline-editing#changing-the-labels) page.

## Row actions

Each row displays a view, edit or delete action, depending on whether you've [enabled the view page, the edit page or the delete action](/docs/admin/resources#adding-pages) for your resource by calling `AllowView()`, `AllowEdit()` or `AllowDelete()`.

StellarAdmin doesn't support custom row actions or bulk actions yet.
