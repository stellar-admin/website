StellarAdmin doesn't add columns automatically, so the grid displays only the columns you add. Call `Add()` in the `Columns()` callback for each column, in the order the grid displays them. The example below adds four columns to the bookings grid, and configures the departure date and notes columns:

```cs
resource.Index(index => index.Columns(columns =>
{
    columns.Add(booking => booking.Reference);
    columns.Add(booking => booking.DepartureDate, column =>
    {
        column.Title = "Departs";
        column.Sortable();
    });
    columns.Add(booking => booking.Total);
    columns.Add(booking => booking.Notes, column => column.EmptyText = "No notes");
}));
```

You configure a column in the callback that you pass to `Add()`:

| Setting | What it does |
| --- | --- |
| `Title` | Sets the column's header. The default is the property's `[Display(Name)]`, or else the property name split into words, such as "Departure Date". |
| `EmptyText` | Sets the text to display when the value is null or empty. The default is the property's `[DisplayFormat(NullDisplayText)]`, or else an empty cell. |
| `Sortable()` | Lets people sort the grid by the column. See [sorting and paging](/docs/admin/sorting-and-paging). |
| `UseDisplay<TDisplay>()` | Renders the value with a different [display type](/docs/admin/displays). |
| `UseBuiltInRendering()` | Renders the value as text, formatted with the property's `[DisplayFormat]`, instead of with a display. |

When you call `Add()` without a callback, it returns the column's builder, so you can chain the methods instead:

```cs
columns.Add(booking => booking.Total).Sortable();
```

## Choosing how values are rendered

Unless specified otherwise, a column renders its value with a [display](/docs/admin/displays) that StellarAdmin chooses from the property's type. For example, numbers are right-aligned, dates are rendered like "3 Nov 2026", a `bool` is rendered as an icon, and an enum is rendered with its `[Display(Name)]`.

To render a value differently, call `UseDisplay()` with the display to use. The example below renders the total as a currency:

```cs
using StellarAdmin.Resources.Displays;

columns.Add(booking => booking.Total, column =>
    column.UseDisplay<NumberDisplay>(number => number.Format = "C"));
```

See [built-in displays](/docs/admin/displays) for every display and its settings.

## Displaying related values

To display a property of a related record, read it through the navigation property. StellarAdmin loads the related record in the same query, so you don't need to call `Include()`. The example below displays the name of the booking's customer:

```cs
columns.Add(booking => booking.Customer!.Name, column => column.Title = "Customer");
```

Set a `Title` on such a column, because the default title is the name of the last property, "Name". When a booking has no customer, the cell displays the column's empty text.

When the related type is a resource, you can add the navigation property itself. The cell displays the related record's [title](/docs/admin/titles-and-references):

```cs
columns.Add(booking => booking.Customer);
```

Don't add the foreign key, such as `booking.CustomerId`, as a column, because the cell displays the key's value instead of the related record. To display a collection of related records, such as a trip's tags, see [showing related values](/docs/admin/related-values).

## Displaying computed values

A column can display any expression, not only a property. The example below displays the total per traveller:

```cs
columns.Add(booking => booking.Total / booking.Travellers, column =>
{
    column.Title = "Per traveller";
    column.Sortable(booking => booking.Total / booking.Travellers);
    column.UseDisplay<NumberDisplay>(number => number.Format = "C");
});
```

A computed column must have a `Title`, because there's no property to take the default title from. StellarAdmin leaves out a computed column without a `Title`, and reports a [configuration problem](/docs/admin/configuration-problems).

StellarAdmin computes the value for each row after loading the records, so the database can't sort by it. To make a computed column sortable, pass the expression to `Sortable()`, so that the database sorts by it. A computed column that calls `Sortable()` without an expression isn't sortable, and StellarAdmin reports a configuration problem.

## Writing your own cell markup

For a value that no built-in display covers, such as a badge whose color depends on the value, write a custom display with a grid template. See [custom displays](/docs/admin/custom-displays).
