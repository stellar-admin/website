StellarAdmin doesn't add columns automatically, so the grid displays only the columns you add. Call `Add()` in the `Columns()` callback for each column, in the order the grid displays them. The example below adds four columns to the bookings grid, and configures the booking date and special requests columns:

```cs
resource.Index(index => index.Columns(columns =>
{
    columns.Add(booking => booking.Reference);
    columns.Add(booking => booking.BookedAt, column =>
    {
        column.Title = "Booked";
        column.Sortable();
    });
    columns.Add(booking => booking.TotalAmount);
    columns.Add(booking => booking.SpecialRequests, column => column.EmptyText = "No requests");
}));
```

You configure a column in the callback that you pass to `Add()`:

| Setting | What it does |
| --- | --- |
| `Title` | Sets the column's header. The default is the property's `[Display(Name)]`, or else the property name split into words, such as "Departure Date". |
| `EmptyText` | Sets the text to display when the value is null or empty. The default is the property's `[DisplayFormat(NullDisplayText)]`, or else an empty cell. |
| `Sortable()` | Lets people [sort the grid](/docs/admin/sorting-and-paging) by the column. |
| `UseDisplay<TDisplay>()` | Renders the value with a different [display type](/docs/admin/displays). |
| `UseBuiltInRendering()` | Renders the value as text, formatted with the property's `[DisplayFormat]`, instead of with a display. |

When you call `Add()` without a callback, it returns the column's builder, so you can chain the methods instead:

```cs
columns.Add(booking => booking.TotalAmount).Sortable();
```

## Choosing how values are rendered

Unless specified otherwise, a column renders its value with a [display type](/docs/admin/displays) that StellarAdmin chooses from the property's type. For example, numbers are right-aligned, dates are rendered like "3 Nov 2026", a `bool` is rendered as an icon, and an enum is rendered with its `[Display(Name)]`.

To render a value differently, call `UseDisplay()` with the display type to use. The example below renders the total as a currency:

```cs
using StellarAdmin.Resources.Displays;

columns.Add(booking => booking.TotalAmount, column =>
    column.UseDisplay<NumberDisplay>(number => number.Format = "C"));
```

See [displays](/docs/admin/displays) for every display type and its settings.

## Displaying related records

To display a related record, such as a booking's traveller, add the navigation property, or read one of the related record's properties through it:

```cs
columns.Add(booking => booking.Traveller);
columns.Add(booking => booking.Traveller.Email, column => column.Title = "Traveller email");
```

See [displaying related records](/docs/admin/related-values) for what the cell displays, how to sort by a related record, and how to display a collection of related records, such as a trip's tags.

## Displaying computed values

A column can display any expression, not only a property. The example below displays the total per traveler:

```cs
columns.Add(booking => booking.TotalAmount / booking.Passengers.Count, column =>
{
    column.Title = "Per traveler";
    column.Sortable(booking => booking.TotalAmount / booking.Passengers.Count);
    column.UseDisplay<NumberDisplay>(number => number.Format = "C");
});
```

A computed column must have a `Title`, because there's no property to take the default title from. StellarAdmin leaves out a computed column without a `Title`, and reports a [configuration problem](/docs/admin/configuration-problems).

StellarAdmin computes the value for each row after loading the records, so the database can't sort by it. To make a computed column sortable, pass the expression to `Sortable()`, so that the database sorts by it. A computed column that calls `Sortable()` without an expression isn't sortable, and StellarAdmin reports a configuration problem.

## Writing your own cell markup

For a value that no built-in display covers, such as a badge whose color depends on the value, write a [custom display](/docs/admin/custom-displays) with a grid template.
