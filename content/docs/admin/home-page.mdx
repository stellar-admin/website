The admin panel's home page is the page at the admin panel's URL, `/stellaradmin` by default, which the title at the top of the sidebar links to.

In the Development environment, the home page is a setup checklist. It lists the steps for setting up StellarAdmin, such as adding resources, protecting the admin panel and setting the branding, and marks the steps you've done. Each step has the code to add, and instructions you can give to a coding agent.

<Screenshot name="home-page-setup-checklist" alt="The setup checklist on the admin panel's home page" />

In other environments, the home page links to the resources the user can open, in the order of the sidebar.

To see that page in Development, turn the setup checklist off:

```cs
admin.ConfigureHomePage(home => home.ShowSetupChecklist = false);
```

## Replacing the home page

To display your own home page, such as a dashboard, add your own `Areas/StellarAdmin/Views/Home/Index.cshtml` to your app, which replaces StellarAdmin's in every environment. The example below displays the number of bookings waiting for confirmation:

```razor title="Areas/StellarAdmin/Views/Home/Index.cshtml"
@inject ApplicationDbContext Db
@{
    ViewData["Title"] = "Dashboard";
    var pending = Db.Bookings.Count(booking => booking.Status == BookingStatus.Pending);
}

<sa-page-container>
    <sa-page-header>
        <sa-page-header-title>Welcome back</sa-page-header-title>
    </sa-page-header>
    <sa-card>
        <sa-card-header>
            <sa-card-title>@pending bookings waiting for confirmation</sa-card-title>
        </sa-card-header>
    </sa-card>
</sa-page-container>
```

Don't declare a `@model`, because the model of StellarAdmin's home page is internal. To load data, inject a service, as in the example above, or use a view component. The folder needs the [view imports](/docs/admin/overriding-pages#view-imports).

StellarAdmin doesn't have dashboard widgets, so build the page with the [StellarAdmin.UI components](/docs/ui).
