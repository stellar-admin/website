## Introduction

StellarAdmin display `string` properties using `TextDisplay`, unless an attribute on the property specifies a different display type, such as `[EmailAddress]`.

## Cutting long text off

By default, `TextDisplay` displays all the text in the string. To cut the text off after a number of lines, set `LineClamp`. The example below displays at most 2 lines of each trip's summary in the grid:

```cs
using StellarAdmin.Resources.Displays;

columns.Add(trip => trip.Summary, column =>
    column.UseDisplay<TextDisplay>(text => text.LineClamp = 2));
```

<Screenshot name="text-displays-line-clamp" alt="The trips grid with each summary cut off after 2 lines" />

In the grid, text with a `LineClamp` wraps at a readable width, instead of widening the column.

## Displaying line breaks

Text that a user entered over several lines, such as in a [textarea](/docs/admin/inputs#entering-long-text), contains line breaks. By default, `TextDisplay` ignores them and displays the text as a single paragraph.

To keep the line breaks in a display field, add `[DataType(DataType.MultilineText)]` to the property. In the grid, the line breaks are kept only when the column sets `LineClamp`.

## Displaying HTML

StellarAdmin displays a property with `[DataType(DataType.Html)]` using `HtmlDisplay`. `HtmlDisplay` [sanitizes the HTML](/docs/admin/rich-text-editor#sanitizing-the-html), and displays it formatted.

In the grid, `HtmlDisplay` displays the text without formatting, cut off after 2 lines. The example below displays 4 lines instead:

```cs
columns.Add(trip => trip.Description, column =>
    column.UseDisplay<HtmlDisplay>(html => html.LineClamp = 4));
```
