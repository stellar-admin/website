---
title: Icons
description: Let people choose an icon instead of typing its name
---

The *icon editor* edits a `string` property that stores an icon's name, such as a trip's or an amenity's icon. People choose from the registered [icons](/docs/ui/icons) instead of typing a name. To use the icon editor, call `UseIconEditor()`:

```cs
fields.Add(trip => trip.Icon).UseIconEditor();
```

By default, the icon editor offers every registered icon in a picker that searches the icons' names and keywords. The picker loads the icons the first time it opens. The icon editor is rendered as an [icon picker](/docs/ui/components/icon-picker).

The picker downloads every registered icon from the server, so register only the icon packs you use.

## Offering a short list of icons

To offer only some icons, set `Icons` to their names. The example below offers five icons:

```cs
using StellarAdmin.Resources.Editors;

fields.Add(trip => trip.Icon).UseIconEditor(icon =>
{
    icon.Icons = ["mountain", "sailboat", "utensils", "landmark", "tent"];
});
```

To choose how the editor displays the icons, set `Layout`:

| `IconEditorLayout` | Displays |
| --- | --- |
| `Auto` | An inline grid of icons when `Icons` has 24 names or fewer. The picker when `Icons` has more names, or isn't set. This is the default. |
| `Picker` | The picker. |
| `Inline` | An inline grid of icons, even when `Icons` has more than 24 names. If `Icons` isn't set, the editor displays the picker, and StellarAdmin reports a [configuration problem](/docs/admin/configuration-problems). |

If a name in `Icons` isn't a registered icon, StellarAdmin leaves the icon out, and reports a [configuration problem](/docs/admin/configuration-problems). If none of the names are registered icons, StellarAdmin leaves the field off the form.

A new value must be one of the offered icons. A stored value that the editor no longer offers still displays, and is saved unchanged, so records with an old icon name stay editable.

In an [inline row](/docs/admin/inline-editing), the icon editor is always a button that opens the picker.
