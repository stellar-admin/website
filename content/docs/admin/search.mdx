title: Search
description: Add a search box to the index page
---

Call `EnableSearch()` to add a search box to the index page. For an EF Core resource, you pass a function that takes the search text and returns the filter to apply. The example below searches bookings by their reference and by the traveller's last name:

```cs
resource.Index(index =>
{
    index.EnableSearch(term => booking =>
        booking.Reference.Contains(term) || booking.Traveller.LastName.Contains(term));
});
```

StellarAdmin trims the search text before passing it to your function. The grid searches as someone types, after a short pause.

The filter runs in the database, so EF Core must be able to translate it to SQL. A property of a related record, such as `booking.Traveller.LastName`, becomes a join.

## Making the search case-insensitive

Whether `Contains()` is case-sensitive depends on your database's collation. On SQLite, and on databases with a case-sensitive collation, it's case-sensitive. To make the search case-insensitive there, convert both sides to lower case:

```cs
index.EnableSearch(term =>
{
    var lowered = term.ToLower();
    return booking => booking.Reference.ToLower().Contains(lowered);
});
```

## Changing the placeholder

The search box's default placeholder is "Search" and the plural label, such as "Search Bookings...". To change it, set `Placeholder` in the callback that you pass as the second argument:

```cs
index.EnableSearch(
    term => booking => booking.Reference.Contains(term),
    search => search.Placeholder = "Search by reference");
```

To change the default placeholder for every resource, see [global labels](/docs/admin/global-labels).

## Searching a custom data source

When a resource uses a [custom data source](/docs/admin/custom-data-sources), call `EnableSearch()` without a filter. StellarAdmin passes the search text via the `Search` property of the `request` parameter when calling the `ListAsync()` method, and your data source decides which records match.

## Searching across resources

The search box searches only the records of its own resource. StellarAdmin doesn't support searching across every resource yet.
