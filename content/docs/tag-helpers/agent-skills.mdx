StellarAdmin provides a **stellar-admin-tag-helpers** skill for agents such as Claude Code and Codex. It includes setup instructions, component references, and guidance for forms, layouts, and theming in ASP.NET Core MVC and Razor Pages `.cshtml` files.

Install it with [Vercel's skills installer](https://github.com/vercel-labs/skills). The skill and its references live in the [StellarAdmin repository](https://github.com/stellar-admin/stellar-admin/tree/master/skills/stellar-admin-tag-helpers).

## Installation

With Node.js/npm and Git installed, open a terminal in your application's project directory and run:

```bash
npx skills add stellar-admin/stellar-admin --skill stellar-admin-tag-helpers
```

Choose your agent in the installer. Installation is project-scoped by default. Keep the explicit `--skill stellar-admin-tag-helpers` selection: the repository also contains internal product-development skills.

To select an agent directly, use one of these commands:

```bash title="Claude Code"
npx skills add stellar-admin/stellar-admin --skill stellar-admin-tag-helpers --agent claude-code
```

```bash title="Codex"
npx skills add stellar-admin/stellar-admin --skill stellar-admin-tag-helpers --agent codex
```

Other agents supported by the installer can use the same skill. Add `--global` if you want it available across projects. Start a fresh agent session in your application after installation.

<Callout type="info">
    This installs agent guidance and bundled references. It does not install the StellarAdmin NuGet package or change your application. Ask your agent to set up StellarAdmin, or follow the [installation guide](/docs/tag-helpers/installation).
</Callout>

## Setting up your application

Ask your agent:

> Use the stellar-admin-tag-helpers skill to install StellarAdmin in this application.

The skill asks you to choose a setup scope unless you already specified one:

- **Basic installation:** install the package, register services and tag helpers, and add CSS and JavaScript references. Preserve the current layout structure and Bootstrap.
- **Installation with layout conversion:** also adapt the default layout to StellarAdmin and remove Bootstrap where it is no longer needed. Check remaining dependencies before removing shared assets.

The agent should offer a picker when its interface supports one, or ask a text question otherwise. Keeping Bootstrap can cause styling conflicts; basic installation does not guarantee that adding the StellarAdmin stylesheet leaves every existing element's appearance unchanged.

## What's included

One skill includes these references, which the agent reads as needed:

| Area | Guidance |
| --- | --- |
| Setup and components | Package setup, tag names, attributes, enum values, composition rules, icons, JavaScript, and templated views. |
| Forms | Fields, validation, model binding, input groups, and choice cards. |
| Layout | Sidebars, app headers, page headers, spacing, and cards. |
| Theming | Theme stylesheets, dark mode, design tokens, and menu appearance. |

For later tasks, ask the agent to use `stellar-admin-tag-helpers` to build a form, add navigation, or customize a theme. Automatic skill selection depends on the agent and task.

## Compatibility and updates

The skill is maintained alongside StellarAdmin. Its references follow the repository's default branch and may include changes newer than your installed NuGet package. The agent should check your installed version before applying API examples. Installing or updating the skill does not update your NuGet packages.

StellarAdmin Dashboard is a separate product still in development and does not yet have an installable skill. This skill covers the Tag Helpers UI library, not Dashboard configuration or resource workflows.
