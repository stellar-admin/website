## Usage

`<dui-alert-dialog>` renders a standard [HTML `dialog` element](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/dialog), styled as a centered confirmation modal. Open it with the [Invoker Commands API](https://developer.mozilla.org/en-US/docs/Web/API/Invoker_commands_API) by adding `commandfor` and `command="show-modal"` to a `<dui-button>`.

Unlike `<dui-dialog>`, an alert dialog is **not** light-dismissable: pressing `Esc` cancels it, but clicking the backdrop does nothing (`closedby="closerequest"` by default). Wrap the footer in a `<form method="dialog">` and use `<dui-alert-dialog-action>` / `<dui-alert-dialog-cancel>` so the dialog closes with the correct `returnValue`.

```razor
<dui-button commandfor="--confirm" command="show-modal">
    Show Dialog
</dui-button>
<dui-alert-dialog id="--confirm">
    <dui-alert-dialog-header>
        <dui-alert-dialog-title>Cancel this booking?</dui-alert-dialog-title>
        <dui-alert-dialog-description>
            This action cannot be undone.
        </dui-alert-dialog-description>
    </dui-alert-dialog-header>
    <form method="dialog">
        <dui-alert-dialog-footer>
            <dui-alert-dialog-cancel>Keep booking</dui-alert-dialog-cancel>
            <dui-alert-dialog-action>Continue</dui-alert-dialog-action>
        </dui-alert-dialog-footer>
    </form>
</dui-alert-dialog>
```

`<dui-alert-dialog-cancel>` renders a submit button with `value="cancel"` and `<dui-alert-dialog-action>` one with `value="confirm"`, so the wrapping `method="dialog"` form closes the dialog and sets `returnValue` accordingly.

### JavaScript API

For the common "await a confirmation before acting" flow, use the `window.duneui.alertDialog()` helper. Its `confirmAsync()` method resolves to `true` when the user activates the action button and `false` on cancel or `Esc`.

<Callout type="tip">
  `alertDialog()` is built on the same primitive as the [`dialog()`
  helper](js-dialog); use it whenever you want to drive a confirmation in an
  async/await style.
</Callout>

## API Reference

### `<dui-alert-dialog>`

The `<dui-alert-dialog>` tag helper renders a native [`<dialog>`
element](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/dialog)
which is opened and closed via the Invoker Commands API
(`command="show-modal"` / `command="close"` on a button whose `commandfor`
targets the dialog's `id`). In addition to the attribute below, it forwards any
standard [`<dialog>`
attributes](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/dialog#attributes)
to the rendered element; `closedby` defaults to `closerequest` so the dialog is
not light-dismissable.

### `<dui-alert-dialog-header>`

The `<dui-alert-dialog-header>` tag helper renders a `<div>` element that groups
the media, title, and description. It has no attributes of its own.

### `<dui-alert-dialog-media>`

The `<dui-alert-dialog-media>` tag helper renders a `<div>` element for showing
an icon or image above the title. It has no attributes of its own.

### `<dui-alert-dialog-title>`

The `<dui-alert-dialog-title>` tag helper renders an `<h2>` element containing
the dialog's title. It has no attributes of its own.

### `<dui-alert-dialog-description>`

The `<dui-alert-dialog-description>` tag helper renders a `<p>` element
containing the dialog's description. It has no attributes of its own.

### `<dui-alert-dialog-footer>`

The `<dui-alert-dialog-footer>` tag helper renders a `<div>` element that lays
out the cancel and action buttons. It has no attributes of its own.

### `<dui-alert-dialog-cancel>`

The `<dui-alert-dialog-cancel>` tag helper renders a `<button type="submit">`
with `value="cancel"` (unless you supply your own `value`), so a wrapping
`<form method="dialog">` closes the dialog with that `returnValue`. It forwards
any standard [`<button>`
attributes](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/button#attributes)
to the rendered element.

### `<dui-alert-dialog-action>`

The `<dui-alert-dialog-action>` tag helper renders a `<button type="submit">`
with `value="confirm"` (unless you supply your own `value`), so a wrapping
`<form method="dialog">` closes the dialog with that `returnValue`. It forwards
any standard [`<button>`
attributes](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/button#attributes)
to the rendered element.
