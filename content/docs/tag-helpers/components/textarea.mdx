## Usage

Renders a styled `<textarea>`. Use `rows` and the other native attributes as usual.

```razor
<sa-textarea />
```

## Examples

### Model binding

Supports ASP.NET Core model binding via `asp-for`. When using model binding, StellarAdmin will automatically wrap the textarea inside a [Field](field) with the correct label, description, and placeholder text derived from data attributes. You can opt out of this behavior by setting the `render-field` attribute to `false`.

When using model binding, validation errors from [Model state](https://learn.microsoft.com/en-us/aspnet/core/mvc/models/validation) are displayed correctly.

### Manual validation

If you're not using ASP.NET Core model binding, you can manually indicate validation errors by setting the `aria-invalid` attribute to `true`. This will display a red border around the text area.

The error message can be displayed using either a `<sa-field-error>` Tag Helper (when using explicit fields) or the `error` attribute (when using implicit fields).

## API Reference

### `<sa-textarea>`

Renders a `<textarea>` element. The `asp-for` attribute provides the same model
binding as the built-in [Textarea Tag
Helper](https://learn.microsoft.com/en-us/aspnet/core/mvc/views/working-with-forms#the-textarea-tag-helper).
