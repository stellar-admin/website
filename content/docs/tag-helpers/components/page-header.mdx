## Usage

Sits at the top of a page's content to display a page title, actions, as well as navigation.

```razor
<sa-page-header>
    <sa-breadcrumb>...</sa-breadcrumb>
    <sa-page-header-title>Bookings</sa-page-header-title>
    <sa-page-header-description>All bookings across destinations.</sa-page-header-description>
    <sa-page-header-actions>
        <sa-button>...</sa-button>
    </sa-page-header-actions>
    <sa-page-header-nav>...</sa-page-header-nav>
</sa-page-header>
```

## API Reference

### `<sa-page-header>`

The `<sa-page-header>` tag helper renders a `<header>` element at the top of a
page's content.

### `<sa-page-header-title>`

The `<sa-page-header-title>` tag helper renders the page title as the page's
`<h1>` element.

### `<sa-page-header-description>`

The `<sa-page-header-description>` tag helper renders a short description below
the title as a `<p>` element.

### `<sa-page-header-actions>`

The `<sa-page-header-actions>` tag helper renders a `<div>` element for content
such as buttons, aligned to the end of the title row on regular viewports and
placed below the title and description on narrow viewports.

### `<sa-page-header-nav>`

The `<sa-page-header-nav>` tag helper renders a full-width `<nav>` element at
the bottom of the header. It positions whatever navigation the page provides
without imposing any styling of its own.
