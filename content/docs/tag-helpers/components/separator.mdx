## API Reference

### `<dui-separator>`

The `<dui-separator>` tag helper renders a `<div>` element with
`role="separator"`. In addition to the attribute below, it forwards any
standard [global
attributes](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes)
(such as `id`, `class`, or `title`) to the rendered element.
