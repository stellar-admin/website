## Usage

Visually separates a group of adjacent elements with a horizontal or vertical line.

```razor
<sa-separator/>
```

## Examples

### Horizontal

## API Reference

### `<sa-separator>`

The `<sa-separator>` Tag Helper renders a `<div>` element with
`role="separator"`.
