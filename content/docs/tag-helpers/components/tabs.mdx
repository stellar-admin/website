## Usage

```razor
<dui-tab-list>
    <dui-tab-link>...</dui-tab-link>
</dui-tab-list>
```

### Url

The URL of `dui-tab-link` can be specified a couple of ways:

1. You can use the `href` property to specify any valid URL [as per the `href` property of the anchor element](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/a#href).
2. You can use any of the attributes that are valid for specifying the URL for the ASP.NET Core Anchor Tag Helper, such as `asp-controller`, `asp-action`, `asp-page`, etc. Please refer to the [Anchor Tag Helper documentation](https://learn.microsoft.com/en-us/aspnet/core/mvc/views/tag-helpers/built-in/anchor-tag-helper) for more examples.

<Demo src="/demo/tag-helpers/tabs-url.html">
  <include>./_include/tabs-url.mdx</include>
</Demo>

When specifying the URL, DuneUI will automatically set the `is-active` attribute for the tab link representing the currently active route, so you should not need to specify the `is-active` attribute explicitly. However, DuneUI can not always determine this correctly - especially if the URL contains query string parameters. In such cases, you can explicitly set the `is-active` attribute to either `true` or `false`.

## API Reference

### `<dui-tab-list>`

The `<dui-tab-list>` tag helper renders a `<div>` element wrapping an inner
tab list `<div>`. In addition to the attributes below, it forwards any [global
HTML
attributes](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes)
to the rendered element.

<TypeTable
  type={{
    orientation: {
      description: "The orientation of the tab list.",
      type: "TabListOrientation",
      typeDescription:
        "TabListOrientation.Horizontal | TabListOrientation.Vertical",
      default: "TabListOrientation.Horizontal",
    },
    variant: {
      description: "The visual style of the tab list.",
      type: "TabListVariant",
      typeDescription: "TabListVariant.Default | TabListVariant.Line",
      default: "TabListVariant.Default",
    },
  }}
/>

### `<dui-tab-link>`

The `<dui-tab-link>` tag helper renders an `<a>` element. In addition to the
attributes below, it forwards any standard [`<a>`
attributes](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/a#attributes)
(such as `href` or `target`) to the rendered element.

<TypeTable
  type={{
    disabled: {
      description:
        "Disables the tab. A disabled tab has its href removed and does not respond to interaction.",
      type: "bool",
      default: "false",
    },
    "is-active": {
      description:
        "Whether the tab is the active tab. When not set, DuneUI determines this from the current route.",
      type: "bool",
    },
  }}
/>

both.
