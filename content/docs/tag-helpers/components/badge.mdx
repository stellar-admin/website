## API Reference

### `<sa-badge>`

The `<sa-badge>` tag helper renders a `<span>` element. In addition to the
attribute below, it forwards any standard [global
attributes](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes)
(such as `id`, `class`, or `title`) to the rendered element.
