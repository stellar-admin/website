## Usage

Use `dui-accordion` to wrap a collection of accordion items. Individual items are created using the `dui-accordion-item` element containing `dui-accordion-item-title` and `dui-accordion-item-content` which contains the title and content respectively.

```razor
<dui-accordion>
    <dui-accordion-item>
        <dui-accordion-item-title>
            ...
        </dui-accordion-item-title>
        <dui-accordion-item-content>
            ...
        </dui-accordion-item-content>
    </dui-accordion-item>
    <dui-accordion-item>
        ...
    </dui-accordion-item>
</dui-accordion>
```

## Examples

### Single open item

The `name` attribute of `dui-accordion-item` allows you to link multiple accordion items to a single group. When they are connected in this manner, only a single item can be opened at a time.

This behavior [is managed by the `<details>` HTML element](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/details#name), which `dui-accordion-item` uses.

## API Reference

### `<dui-accordion>`

The `<dui-accordion>` tag helper renders a `<div>` element that wraps the
accordion items. It has no attributes of its own, but forwards any [global
HTML
attributes](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes)
(such as `class` or `id`) to the rendered element.

### `<dui-accordion-item>`

The `<dui-accordion-item>` tag helper renders a `<details>` element. It has no
attributes of its own, but forwards any standard [`<details>`
attributes](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/details#attributes)
(such as `name` or `open`) to the rendered element; adding a `disabled`
attribute renders the item as disabled.

### `<dui-accordion-item-title>`

The `<dui-accordion-item-title>` tag helper renders a `<summary>` element and
appends a chevron indicator icon after the title content. It has no attributes
of its own, but forwards any [global HTML
attributes](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes)
to the rendered element.

### `<dui-accordion-item-content>`

The `<dui-accordion-item-content>` tag helper renders a `<div>` element
containing an inner content wrapper. It has no attributes of its own, but
forwards any [global HTML
attributes](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes)
to the rendered element.
