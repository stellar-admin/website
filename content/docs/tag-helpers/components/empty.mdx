## Usage

```razor
<sa-empty>
    <sa-empty-header>
        <sa-empty-media>...</sa-empty-media>
        <sa-empty-title>...</sa-empty-title>
        <sa-empty-description>...</sa-empty-description>
    </sa-empty-header>
    <sa-empty-content>
        ...
    </sa-empty-content>
</sa-empty>
```

## API Reference

### `<sa-empty>`

The `<sa-empty>` tag helper renders a `<div>` element that centers the empty
state content.

### `<sa-empty-header>`

The `<sa-empty-header>` tag helper renders a `<div>` element grouping the media,
title, and description.

### `<sa-empty-media>`

The `<sa-empty-media>` tag helper renders a `<div>` element for displaying an
icon, image, or avatar.

<TypeTable
  type={{
    variant: {
      description: "The visual style of the media container.",
      type: "EmptyMediaVariant",
      typeDescription: "EmptyMediaVariant.Default | EmptyMediaVariant.Icon",
      default: "EmptyMediaVariant.Default",
    },
  }}
/>

### `<sa-empty-title>`

The `<sa-empty-title>` tag helper renders a `<div>` element containing the
title.

### `<sa-empty-description>`

The `<sa-empty-description>` tag helper renders a `<div>` element containing the
description.

### `<sa-empty-content>`

The `<sa-empty-content>` tag helper renders a `<div>` element for actions such
as buttons or links.
