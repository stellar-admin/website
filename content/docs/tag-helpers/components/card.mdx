## Usage

```razor
<sa-card>
    <sa-card-header>
        <sa-card-title>...</sa-card-title>
        <sa-card-description>...</sa-card-description>
    </sa-card-header>
    <sa-card-content>
        ...
    </sa-card-content>
    <sa-card-footer>...</sa-card-footer>
</sa-card>
```

## API Reference

### `<sa-card>`

The `<sa-card>` tag helper renders a `<div>` element. In addition to the
attributes below, it forwards any standard [global
attributes](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes)
(such as `class`) to the rendered element.

<TypeTable
  type={{
    size: {
      description: "The size of the card.",
      type: "CardSize",
      typeDescription: "CardSize.Default | CardSize.Small",
      default: "CardSize.Default",
    },
  }}
/>

### `<sa-card-header>`

The `<sa-card-header>` tag helper renders a `<div>` element grouping the
title, description, and optional action. It has no attributes of its own.

### `<sa-card-title>`

The `<sa-card-title>` tag helper renders a `<div>` element containing the
title. It has no attributes of its own.

### `<sa-card-description>`

The `<sa-card-description>` tag helper renders a `<div>` element containing
the description. It has no attributes of its own.

### `<sa-card-action>`

The `<sa-card-action>` tag helper renders a `<div>` element positioned in the
top-right corner of the header, for actions such as buttons. It has no
attributes of its own.

### `<sa-card-content>`

The `<sa-card-content>` tag helper renders a `<div>` element containing the
main content. It has no attributes of its own.

### `<sa-card-footer>`

The `<sa-card-footer>` tag helper renders a `<div>` element containing the
footer content. It has no attributes of its own.
