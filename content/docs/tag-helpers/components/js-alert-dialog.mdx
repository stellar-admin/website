The `alertDialog()` function is a confirmation-focused wrapper around the [`dialog()` helper](js-dialog) for use with the [Alert Dialog](alert-dialog) component. Since an alert dialog's whole purpose is "await a confirmation before doing something", the wrapper exposes a boolean-returning `confirmAsync()` method: it resolves `true` when the user activates the action button, and `false` when the dialog is cancelled or dismissed with the `Esc` key.

## Usage

```js
const alertDialog = window.stellarAdmin.alertDialog(document.getElementById("myAlertDialog"));
if (await alertDialog.confirmAsync()) {
  // perform the confirmed action
}
```

## API Reference

### `alertDialog(selector)`

The `alertDialog()` factory function, exposed as `window.stellarAdmin.alertDialog`, wraps an existing `<dialog>` element (such as the one rendered by `<sa-alert-dialog>`) and returns a wrapper object with the methods below. It throws if the element cannot be found or is not a `HTMLDialogElement`.
