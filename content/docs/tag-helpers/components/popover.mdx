## Usage

`<sa-popover>` uses the [HTML Popover API](https://developer.mozilla.org/en-US/docs/Web/API/Popover_API) and renders a `div` element with a `popover` attribute. The popover can be opened by using the `popovertarget` attribute on a `<sa-button>` element.

```razor
<sa-button popovertarget="--my-popover">Element that triggers popover</sa-button>
<sa-popover id="--my-popover">
  <!-- add the popover content here -->
</sa-popover>
```

### Manual dismiss

By default, `<sa-popover>` is light dismissable - meaning you can hide the popover by clicking outside of it or pressing the `Esc` key. You can change this behaviour by setting the `popover` attribute to `manual` which will require it to be explicitly closed using `popovertargetaction="hide"` or JavaScript.

### JavaScript API

Since `<sa-popover>` uses the [Popover API](https://developer.mozilla.org/en-US/docs/Web/API/Popover_API/Using), you can use the `showPopover()`, `hidePopover()` and `togglePopover()` methods to control visibility of the popover.

When using the JavaScript API, you also need to make sure you specify the `source` element to ensure the tooltip is aligned correctly with the UI element for which the tooltip is shown.

### JavaScript Events

The [Popover API](https://developer.mozilla.org/en-US/docs/Web/API/Popover_API/Using) fires the `beforetoggle` and `toggle` events on `<sa-popover>` before it is shown/hidden and after it is show/hidden respectively. You can prevent opening the popover by calling `event.preventDefault()` in the `beforetoggle` event handler.

## API Reference

### `<sa-popover>`

The `<sa-popover>` tag helper renders a `<div>` element with a `popover`
attribute (which you can override by supplying your own `popover` attribute,
e.g. `popover="manual"`), opened by a button whose `popovertarget` attribute
references the popover's `id`. In addition to the attribute below, it forwards
any standard [global
attributes](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes)
(such as `id` or `class`) to the rendered element.

<TypeTable
  type={{

      default: "PositionArea.Bottom",
    },
  }}
/>

### `<sa-popover-header>`

The `<sa-popover-header>` tag helper renders a `<div>` element that groups the
popover's title and description. It has no attributes of its own and forwards
any standard [global
attributes](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes)
to the rendered element.

### `<sa-popover-title>`

The `<sa-popover-title>` tag helper renders an `<h2>` element. It has no
attributes of its own and forwards any standard [global
attributes](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes)
to the rendered element.

### `<sa-popover-description>`

The `<sa-popover-description>` tag helper renders a `<p>` element. It has no
attributes of its own and forwards any standard [global
attributes](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes)
to the rendered element.
