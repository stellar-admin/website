## Usage

```razor
<dui-linkbutton>Proceed</dui-linkbutton>
```

## Examples

### URL

The URL of a link button can be specified a couple of ways:

1. You can use the `href` property to specify any valid URL [as per the `href` property of the anchor element](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/a#href).
2. You can use any of the attributes that are valid for specifying the URL for the ASP.NET Core Anchor Tag Helper, such as `asp-controller`, `asp-action`, `asp-page`, etc. Please refer to the [Anchor Tag Helper documentation](https://learn.microsoft.com/en-us/aspnet/core/mvc/views/tag-helpers/built-in/anchor-tag-helper) for more examples.

<Demo src="/demo/tag-helpers/link-button-url.html">
  <include>./_include/link-button-url.mdx</include>

<Callout type="warn">
  The same rules as for the `AnchorTagHelper` are applicable in that you cannot
  specify overlapping URL-related attributes. For example, if you specify an
  `href` attribute along with any of the `asp-*` attributes, an exception will
  be thrown. Likewise, if you specify an `asp-controller` attribute, as well as
  an `asp-page` attribute, an exception will be thrown.
</Callout>

## API Reference

### `<dui-linkbutton>`

The `<dui-linkbutton>` tag helper renders an `<a>` element styled as a button.
In addition to the attributes below, it forwards any standard [`<a>`
attributes](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/a#attributes)
(such as `href`, `target`, or `rel`) to the rendered element.

<TypeTable
  type={{
    size: {
      description: "The size of the button.",
      type: "ButtonSize",
      typeDescription:
        "ButtonSize.Default | ButtonSize.ExtraSmall | ButtonSize.Small | ButtonSize.Large | ButtonSize.Icon | ButtonSize.IconExtraSmall | ButtonSize.IconSmall | ButtonSize.IconLarge",
      default: "ButtonSize.Default",
    },
    variant: {
      description: "The visual style of the button.",
      type: "ButtonVariant",
      typeDescription:
        "ButtonVariant.Default | ButtonVariant.Destructive | ButtonVariant.Outline | ButtonVariant.Secondary | ButtonVariant.Ghost | ButtonVariant.Link",
      default: "ButtonVariant.Default",
    },
  }}
/>

#### Routing attributes

The link button also accepts the same routing attributes as the ASP.NET Core
[Anchor Tag
Helper](https://learn.microsoft.com/en-us/aspnet/core/mvc/views/tag-helpers/built-in/anchor-tag-helper)
for generating the `href`. Supply either an `href` or these attributes — not
both.
