## Usage

```razor
<sa-stack>...</sa-stack>
```

## Examples

### Gap

Control the vertical gap between items with the `gap` attribute. You can specify a custom gap by adding a `class` from [Tailwind's `gap-` utility](https://tailwindcss.com/docs/gap).

</Demo>

## API Reference

### `<sa-stack>`

The `<sa-stack>` tag helper renders a `<div>` element laid out as a vertical
flex container. In addition to the attributes below, it forwards any standard
[global HTML
attributes](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes)
(such as `id` or `class`) to the rendered element.
