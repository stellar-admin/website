## Usage

The `<sa-input-otp>` Tag Helper renders a segmented input for one-time passwords and verification codes. It is backed by a single real `<input>` that holds the whole code, made transparent and laid over the character slots, so it receives focus and keystrokes and model-binds and posts back like any other text field. A small `sel-input-otp` web component distributes what you type into the slots, moves the active slot and caret, and enforces the allowed character `pattern`.

Use the `max-length` attribute to control how many characters the code has.

```razor
<sa-input-otp max-length="6"/>
```

<Callout type="warn">
  Input OTP only submits a value when you set `asp-for` or `name`. Just like a
  native input without a `name`, an Input OTP without one (such as most of the
  examples on this page) renders and is fully interactive but posts nothing. Use
  `asp-for` to [model bind](#model-binding), or set `name` to post a value
  without binding.
</Callout>

### Model binding

The `<sa-input-otp>` Tag Helper has full support for ASP.NET Core model binding using the `asp-for` attribute. Bind it to a `string` and the whole code posts straight back to the property.

When using model binding, StellarAdmin will automatically wrap the input inside a [Field](field) with the correct label and description derived from data attributes. You can opt out of this behavior by setting the `render-field` attribute to `false`.

### Validation

Validation works like any other model-bound field. Add validation attributes to your model and the slots reflect the invalid state, with the error message rendered below.

<Demo src="/demo/tag-helpers/input-otp-validation.html">

    <Tab value="Razor">
      <include>./_include/input-otp-validation.mdx</include>
    </Tab>
    <Tab value="Model">
    ```cs
    public class ValidationModel
    {
        [Display(
            Name = "One-time password",
            Description = "Enter the 6-digit code we sent to your phone."
        )]
        [Required(ErrorMessage = "Enter the complete 6-digit code")]
        [StringLength(6, MinimumLength = 6, ErrorMessage = "Enter the complete 6-digit code")]
        public string OneTimePassword { get; set; } = "123";
    }
    ```
    </Tab>
  </Tabs>

## Accessibility

`<sa-input-otp>` renders a single native `<input>` behind the visible slots, so typing, Backspace, the arrow keys and pasting behave like a normal text input. It sets `inputmode="numeric"` by default so mobile keyboards show digits, and `autocomplete="one-time-code"` so browsers can offer a code they received. With `asp-for` or the `label` attribute the label is wired to the input for you.

When the field has a model state error, or when you set `aria-invalid="true"`, the input and every slot render `aria-invalid="true"`.

## API Reference

### `<sa-input-otp>`

The `<sa-input-otp>` Tag Helper renders a `<sel-input-otp>` web component
containing the slot cells and a single transparent `<input>` element that holds
the whole code and posts it as one form value. When `asp-for` is set, it
delegates to the built-in [ASP.NET Core Input Tag
Helper](https://learn.microsoft.com/en-us/aspnet/core/mvc/views/working-with-forms#the-input-tag-helper)
to resolve the input's name, value, and validation attributes.

### `<sa-input-otp-group>`

The `<sa-input-otp-group>` Tag Helper renders a `<div>` element that groups a
run of slots.

### `<sa-input-otp-slot>`

The `<sa-input-otp-slot>` Tag Helper renders a `<div>` element that displays one
character of the code and the active caret.

### `<sa-input-otp-separator>`

The `<sa-input-otp-separator>` Tag Helper renders a `<div>` element with
`role="separator"`, containing a minus icon by default — supply child content to
override it.
