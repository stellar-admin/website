## Usage

Wrap the sidebar and your page content in a `dui-sidebar-wrapper`. The `dui-sidebar` holds the navigation — composed of `dui-sidebar-header`, `dui-sidebar-content` and `dui-sidebar-footer` — while `dui-sidebar-inset` holds the main page content. Navigation is built up from `dui-sidebar-group`, `dui-sidebar-menu`, `dui-sidebar-menu-item` and `dui-sidebar-menu-link`. Use `dui-sidebar-trigger` to toggle the sidebar.

```razor
<dui-sidebar-wrapper>
    <dui-sidebar>
        <dui-sidebar-header>
            ...
        </dui-sidebar-header>
        <dui-sidebar-content>
            <dui-sidebar-group>
                <dui-sidebar-group-label>Platform</dui-sidebar-group-label>
                <dui-sidebar-group-content>
                    <dui-sidebar-menu>
                        <dui-sidebar-menu-item>
                            <dui-sidebar-menu-link href="...">
                                <dui-icon name="layout-dashboard" />
                                <span>Dashboard</span>
                            </dui-sidebar-menu-link>
                        </dui-sidebar-menu-item>
                    </dui-sidebar-menu>
                </dui-sidebar-group-content>
            </dui-sidebar-group>
        </dui-sidebar-content>
        <dui-sidebar-footer>
            ...
        </dui-sidebar-footer>
    </dui-sidebar>
    <dui-sidebar-inset>
        <dui-sidebar-trigger />
        <!-- Main page content -->
    </dui-sidebar-inset>
</dui-sidebar-wrapper>
```

## API Reference

### `<dui-sidebar-wrapper>`

The `<dui-sidebar-wrapper>` tag helper renders a `<del-sidebar>` web component
that wraps the sidebar and page content and owns the open/collapsed state.
Nested `<dui-sidebar-trigger>` elements toggle it through the Invoker Commands
API; it honours a user-supplied `id` and generates one otherwise. It forwards
any standard [global
attributes](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes)
to the rendered element.

### `<dui-sidebar>`

The `<dui-sidebar>` tag helper renders the sidebar panel itself as a `<div>`
(including the mobile drawer and its backdrop). It forwards any standard
[global
attributes](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes)
to the rendered element.

### `<dui-sidebar-trigger>`

The `<dui-sidebar-trigger>` tag helper renders a `<button>` that toggles the
sidebar via the Invoker Commands API (`command="--toggle-sidebar"` targeting
the wrapper). It shows a default panel icon unless you supply child content,
and forwards any standard [`<button>`
attributes](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/button#attributes)
to the rendered element.

### `<dui-sidebar-header>`

The `<dui-sidebar-header>` tag helper renders a `<div>` for content pinned to
the top of the sidebar. It has no attributes of its own.

### `<dui-sidebar-content>`

The `<dui-sidebar-content>` tag helper renders a `<div>` holding the scrollable
body of the sidebar. It has no attributes of its own.

### `<dui-sidebar-footer>`

The `<dui-sidebar-footer>` tag helper renders a `<div>` for content pinned to
the bottom of the sidebar. It has no attributes of its own.

### `<dui-sidebar-inset>`

The `<dui-sidebar-inset>` tag helper renders a `<main>` element holding the
page content next to the sidebar. It has no attributes of its own.

### `<dui-sidebar-separator>`

The `<dui-sidebar-separator>` tag helper renders a horizontal `<div
role="separator">` inside the sidebar. It has no attributes of its own.

### `<dui-sidebar-group>`

The `<dui-sidebar-group>` tag helper renders a `<div>` for a section of the
sidebar. It has no attributes of its own.

### `<dui-sidebar-group-label>`

The `<dui-sidebar-group-label>` tag helper renders a `<div>` heading for a
group. It has no attributes of its own.

### `<dui-sidebar-group-content>`

The `<dui-sidebar-group-content>` tag helper renders a `<div>` holding a
group's content. It has no attributes of its own.

### `<dui-sidebar-menu>`

The `<dui-sidebar-menu>` tag helper renders a `<ul>` containing menu items. It
has no attributes of its own.

### `<dui-sidebar-menu-item>`

The `<dui-sidebar-menu-item>` tag helper renders an `<li>` for a single menu
entry. It has no attributes of its own.

### `<dui-sidebar-menu-button>`

The `<dui-sidebar-menu-button>` tag helper renders a `<button>` styled as a
menu entry — typically paired with `<dui-collapsible>` for expandable items. In
addition to the attributes below, it forwards any standard [`<button>`
attributes](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/button#attributes)
to the rendered element.

### `<dui-sidebar-menu-link>`

The `<dui-sidebar-menu-link>` tag helper renders an
[`<a>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/a#attributes)
element styled as a menu entry. It is marked active automatically when its
routing attributes match the current route.

### `<dui-sidebar-menu-badge>`

The `<dui-sidebar-menu-badge>` tag helper renders a `<div>` badge (such as a
count) alongside a menu entry. It has no attributes of its own.

### `<dui-sidebar-menu-sub>`

The `<dui-sidebar-menu-sub>` tag helper renders a `<ul>` containing nested
sub-items. It has no attributes of its own.

### `<dui-sidebar-menu-sub-item>`

The `<dui-sidebar-menu-sub-item>` tag helper renders an `<li>` for a single
sub-entry. It has no attributes of its own.
