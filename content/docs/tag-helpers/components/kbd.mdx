## Usage

Wrap a key name in `<sa-kbd>`. Use `<sa-kbd-group>` for combinations.

```razor
<sa-kbd>...</sa-kbd>
```

## API Reference

### `<sa-kbd>`

Renders a `<kbd>` element representing a single key.

### `<sa-kbd-group>`

Renders a `<kbd>` element that groups multiple keys together.
