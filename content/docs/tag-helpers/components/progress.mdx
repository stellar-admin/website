## Usage

Set `value` and optionally add a label and an `<sa-progress-value>` readout.

```razor
<sa-progress value="...">
    <sa-progress-label>...</sa-progress-label>
    <sa-progress-value/>
</sa-progress>
```

## API Reference

### `<sa-progress>`

Renders a `<div>` element containing the progress track and indicator.

<TypeTable
  type={{
    maximum: {
      description: "The maximum value. Must be greater than minimum.",
      type: "int",
      default: "100",
    },
    minimum: {
      description: "The minimum value. Must be less than maximum.",
      type: "int",
      default: "0",
    },
    value: {
      description:
        "The current value. Must be between minimum and maximum.",
      type: "int",
      default: "0",
    },
  }}
/>

### `<sa-progress-label>`

Renders a `<span>` element containing the label text.

### `<sa-progress-value>`

Renders a `<span>` element. When it has no content, it displays the percentage completed, calculated from the parent `<sa-progress>` values.
