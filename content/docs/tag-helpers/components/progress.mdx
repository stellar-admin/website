## Usage

```razor
<sa-progress value="...">
    <sa-progress-label>...</sa-progress-label>
    <sa-progress-value/>
</sa-progress>
```

## API Reference

### `<sa-progress>`

The `<sa-progress>` tag helper renders a `<div>` element containing the
progress track and indicator. In addition to the attributes below, it forwards
any [global HTML
attributes](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes)
to the rendered element.

<TypeTable
  type={{
    maximum: {
      description: "The maximum value. Must be greater than minimum.",
      type: "int",
      default: "100",
    },
    minimum: {
      description: "The minimum value. Must be less than maximum.",
      type: "int",
      default: "0",
    },
    value: {
      description:
        "The current value. Must be between minimum and maximum.",
      type: "int",
      default: "0",
    },
  }}
/>

### `<sa-progress-label>`

The `<sa-progress-label>` tag helper renders a `<span>` element containing
the label text. It has no attributes of its own, but forwards any [global HTML
attributes](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes)
to the rendered element.

### `<sa-progress-value>`

The `<sa-progress-value>` tag helper renders a `<span>` element. When it has
no content, it displays the percentage completed, calculated from the parent
`<sa-progress>` values. It has no attributes of its own, but forwards any
[global HTML
attributes](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes)
to the rendered element.
