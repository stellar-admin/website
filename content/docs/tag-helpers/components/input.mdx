## Usage

The Input Tag Helper generates an [HTML Input Element](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/input) and uses the built-in [ASP.NET Core Input Tag Helper](https://learn.microsoft.com/en-us/aspnet/core/mvc/views/working-with-forms#the-input-tag-helper) internally.

```razor
<sa-input/>
```

The same rules as for the built-in Tag Helper apply to things like data binding and resolving input types from data annotation attributes.

## Examples

### Model binding

The `sa-input` Tag Helper has full support for ASP.NET Core model binding using the `asp-for` attribute. When using model binding, StellarAdmin will automatically wrap the input inside a [Field](field) with the correct label, description, and placeholder text derived from data attributes. You can opt out of this behavior by setting the `render-field` attribute to `false`.

### Manual validation

If you're not using ASP.NET Core model binding, you can manually indicate validation errors by setting the `aria-invalid` attribute to `true`. This will display a red border around the input.

The error message can be displayed using either a `sa-field-error` Tag Helper (when using explicit fields) or the `error` attribute (when using implicit fields).

### Infer input types via model binding

When you use model binding, the input type will be inferred from the underlying data type and data annotations. For more information on this, refer to the built-in [ASP.NET Core Input Tag Helper documentation](https://learn.microsoft.com/en-us/aspnet/core/mvc/views/working-with-forms#the-input-tag-helper).

## API Reference

### `<sa-input>`

The `<sa-input>` tag helper renders an `<input>` element (checkbox and radio
inputs are additionally wrapped in a `<span>` that hosts the indicator icon).
When `asp-for` is set, it delegates to the built-in [ASP.NET Core Input Tag
Helper](https://learn.microsoft.com/en-us/aspnet/core/mvc/views/working-with-forms#the-input-tag-helper)
to resolve the input type, value, and validation attributes.
