## Usage

Renders an animated loading indicator. Its size and color follow the surrounding text unless overridden with utility classes.

```razor
<sa-spinner/>
```

## API Reference

### `<sa-spinner>`

Renders an `<svg>` element containing a spinner icon, with `role="status"` and
`aria-label="Loading"` applied.
