## Usage

Build the pager from `<sa-pagination-item>`s inside `<sa-pagination-content>`, using the first, previous, link, ellipsis, next and last tags for each item.

```razor
<sa-pagination>
    <sa-pagination-content>
        <sa-pagination-item>
            <sa-pagination-first href="#"/>
        </sa-pagination-item>
        <sa-pagination-item>
            <sa-pagination-previous href="#"/>
        </sa-pagination-item>
        <sa-pagination-item>
            <sa-pagination-link href="#">1</sa-pagination-link>
        </sa-pagination-item>
        <sa-pagination-item>
            <sa-pagination-ellipsis/>
        </sa-pagination-item>
        <sa-pagination-item>
            <sa-pagination-next href="#"/>
        </sa-pagination-item>
        <sa-pagination-item>
            <sa-pagination-last href="#"/>
        </sa-pagination-item>
    </sa-pagination-content>
</sa-pagination>
```

## Examples

### URL

The URL of `sa-pagination-link`, `sa-pagination-first`, `sa-pagination-previous`, `sa-pagination-next`, and `sa-pagination-last` can be specified a couple of ways:

1. You can use the `href` property to specify any valid URL [as per the `href` property of the anchor element](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/a#href).
2. You can use any of the attributes that are valid for specifying the URL for the ASP.NET Core Anchor Tag Helper, such as `asp-controller`, `asp-action`, `asp-page`, etc. Please refer to the [Anchor Tag Helper documentation](https://learn.microsoft.com/en-us/aspnet/core/mvc/views/tag-helpers/built-in/anchor-tag-helper) for more examples.

## Accessibility

`<sa-pagination>` renders a `<nav>` landmark labelled "pagination". Set `is-active` on the link for the current page so it renders `aria-current="page"`. The First, Previous, Next and Last links render a text label next to their icon, and `<sa-pagination-ellipsis>` is decorative and hidden from assistive technology.

If you replace the content of the First, Previous, Next or Last links, keep a text label. When the replacement is only an icon, add the text in a `<span class="sr-only">`.

## API Reference

### `<sa-pagination>`

The `<sa-pagination>` tag helper renders a `<nav>` element with
`role="navigation"` and `aria-label="pagination"`.

### `<sa-pagination-content>`

The `<sa-pagination-content>` tag helper renders a `<ul>` element containing the
pagination items.

### `<sa-pagination-item>`

The `<sa-pagination-item>` tag helper renders an `<li>` element wrapping a
single link.

### `<sa-pagination-first>`

The `<sa-pagination-first>` tag helper renders an `<a>` element styled as a
ghost button. When empty, it renders a chevron icon and "First" text by default.
It accepts the same [routing attributes](#routing-attributes) as
`<sa-pagination-link>`.

#### Routing attributes

The pagination links also accept the same routing attributes as the ASP.NET
Core [Anchor Tag
Helper](https://learn.microsoft.com/en-us/aspnet/core/mvc/views/tag-helpers/built-in/anchor-tag-helper)
for generating the `href`. Supply either an `href` or these attributes — not
both. These attributes are accepted by `<sa-pagination-link>`,
`<sa-pagination-first>`, `<sa-pagination-previous>`, `<sa-pagination-next>`,
and `<sa-pagination-last>`.

### `<sa-pagination-ellipsis>`

The `<sa-pagination-ellipsis>` tag helper renders a `<span>` element with
`aria-hidden="true"`. When empty, it renders an ellipsis icon with
screen-reader-only "More pages" text by default.

button. When empty, it renders "Next" text and a chevron icon by default. It
accepts the same [routing attributes](#routing-attributes) as
`<sa-pagination-link>`.
