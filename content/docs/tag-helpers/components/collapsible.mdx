## Usage

```razor
<sa-button commandfor="my-collapsible" command="--toggle">
    <!-- add the element that triggers the collapsible content here -->
</sa-button>
<sa-collapsible id="my-collapsible" hidden="">
    <!-- add the collapsible content here -->
</sa-collapsible>
```

## API Reference

### `<sa-collapsible>`

The `<sa-collapsible>` tag helper renders a `<sel-collapsible>` custom element
and has no attributes of its own; it forwards any standard [global
attributes](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes)
(such as `id`, `class`, or `hidden`) to the rendered element. Give it an `id`
(and the `hidden` attribute to start collapsed), and toggle it via the native
Invoker Commands API using a button with `command="--toggle"` and `commandfor`
referencing that `id`.
