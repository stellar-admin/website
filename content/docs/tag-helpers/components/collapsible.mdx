## Usage

Point a button at the collapsible with `commandfor` and `command="--toggle"`. Add `hidden` to render the content collapsed.

```razor
<sa-button commandfor="my-collapsible" command="--toggle">
    <!-- add the element that triggers the collapsible content here -->
</sa-button>
<sa-collapsible id="my-collapsible" hidden="">
    <!-- add the collapsible content here -->
</sa-collapsible>
```

### Expanded by default

A collapsible is open unless it carries the `hidden` attribute. Leave `hidden`
off to render the content expanded on page load. The trigger's `aria-expanded`
state is set accordingly, so any `in-aria-expanded:` icon swaps still work.

## API Reference

### `<sa-collapsible>`

Renders a `<sel-collapsible>` custom element. Give it an `id` (and the `hidden`
attribute to start collapsed), and toggle it via the native Invoker Commands API
using a button with `command="--toggle"` and `commandfor` referencing that `id`
.
