## Usage

```razor
<sa-item variant="...">
    <sa-item-header>
        ...
    </sa-item-header>
    <sa-item-media>
        ...
    </sa-item-media>
    <sa-item-content>
        <sa-item-title>...</sa-item-title>
        <sa-item-description>...</sa-item-description>
    </sa-item-content>
    <sa-item-actions>
        ...
    </sa-item-actions>
    <sa-item-footer>
        ...
    </sa-item-footer>
</sa-item>
```

### Clickable items

If you want to make the entire item clickable, use `sa-link-item` instead of `sa-item`.

<Demo src="/demo/tag-helpers/item-link.html">
  <include>./_include/item-link.mdx</include>

The URL can be specified a couple of ways:

1. You can use the `href` property to specify any valid URL [as per the `href` property of the anchor element](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/a#href).
2. You can use any of the attributes that are valid for specifying the URL for the ASP.NET Core Anchor Tag Helper, such as `asp-controller`, `asp-action`, `asp-page`, etc. Please refer to the [Anchor Tag Helper documentation](https://learn.microsoft.com/en-us/aspnet/core/mvc/views/tag-helpers/built-in/anchor-tag-helper) for more examples.

### `<sa-item>`

The `<sa-item>` tag helper renders a `<div>` element.

### `<sa-link-item>`

The `<sa-link-item>` tag helper renders an `<a>` element styled as an item,
making the entire item clickable.

### `<sa-item-group>`

The `<sa-item-group>` tag helper renders a `<div>` element with `role="list"`
that groups items together, forwarding any [global
attributes](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes).

### `<sa-item-header>`

The `<sa-item-header>` tag helper renders a `<div>` element for the item
header, forwarding any [global
attributes](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes).

### `<sa-item-media>`

The `<sa-item-media>` tag helper renders a `<div>` element that hosts an icon,
image, or avatar.

<TypeTable
  type={{
    variant: {
      description: "The type of media the element contains.",
      type: "ItemMediaVariant",
      typeDescription:
        "ItemMediaVariant.Default | ItemMediaVariant.Icon | ItemMediaVariant.Image",
      default: "ItemMediaVariant.Default",
    },
  }}
/>

### `<sa-item-content>`

The `<sa-item-content>` tag helper renders a `<div>` element that groups the
item title and description, forwarding any [global
attributes](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes).

### `<sa-item-title>`

The `<sa-item-title>` tag helper renders a `<div>` element for the item title,
forwarding any [global
attributes](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes).

### `<sa-item-description>`

The `<sa-item-description>` tag helper renders a `<p>` element for the item
description, forwarding any [global
attributes](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes).

### `<sa-item-actions>`

The `<sa-item-actions>` tag helper renders a `<div>` element that hosts
buttons or other actions, forwarding any [global
attributes](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes).

### `<sa-item-footer>`

The `<sa-item-footer>` tag helper renders a `<div>` element for the item
footer, forwarding any [global
attributes](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes).

### `<sa-item-separator>`

The `<sa-item-separator>` tag helper renders a horizontal separator (a `<div>`
with `role="separator"`) between items, forwarding any [global
attributes](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes).
