## Usage

Wrap the main content of a page in a `<sa-page-container>`. It centers the content horizontally, applies a consistent gutter, and can constrain the content to a maximum width via the `width` attribute.

```razor
<sa-page-container width="PageContainerWidth.Medium">
    ...
</sa-page-container>
```
