## Usage

```razor
<dui-icon name="..."/>
```

To find the `name` of an icon, go to the [Lucide icons page](https://lucide.dev/icons/) and search for the icon you want to use. When you hover over the icon, the name is displayed in a tooltip.

## API Reference

### `<dui-icon>`

The `<dui-icon>` tag helper renders an inline [`<svg>`
element](https://developer.mozilla.org/en-US/docs/Web/SVG/Reference/Element/svg).
Any standard `<svg>` attributes you supply (such as `class` or `stroke-width`)
are forwarded to the rendered element and take precedence over the icon's
default attributes.
