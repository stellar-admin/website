## API Reference

### `<sa-button>`

The `<sa-button>` tag helper renders a `<button>` element. In addition to the
attributes below, it forwards any standard [`<button>`
attributes](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/button#attributes)
(such as `type`, `disabled`, or `aria-invalid`) to the rendered element.
