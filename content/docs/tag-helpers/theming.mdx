## Dark mode

Dark mode is applied by adding the `dark` CSS class on a containing element such as the `<html>` or `<body>` element. All the content of that element will then render in dark mode.

```razor
<html lang="en" class="dark">
```

How the `dark` class gets added is completely up to you. You can render it server-side from a saved user preference, or toggle it on the client. The script below demonstrates a minimal client-side approach that honors a saved choice and falls back to the operating system setting. Place it in `<head>`, before the theme stylesheet.

```html
<script>
    (function () {
        var saved = null;
        try { saved = localStorage.getItem("theme"); } catch (e) { }
        var prefersDark = window.matchMedia("(prefers-color-scheme: dark)").matches;
        var dark = saved === "dark" || (saved !== "light" && prefersDark);
        document.documentElement.classList.toggle("dark", dark);
        document.documentElement.style.colorScheme = dark ? "dark" : "light";
    })();
</script>
```

Setting `color-scheme` alongside the class keeps native controls such as scrollbars and form elements in step with the page.

## Theme stylesheets

StellarAdmin ships thirteen themes: Concourse, Ice, Ledger, Luma, Lyra, Maia, Meridian, Mira, Nova, Observatory, Rhea, Sera, and Vega. Use the picker above any component example to compare them. The eight shadcn-derived themes share a base palette and differ in shape, spacing, and component styling. Concourse, Ice, Ledger, Meridian, and Observatory are independently designed themes with their own palettes, typography, and control treatments.

When installing StellarAdmin Tag Helpers, you **must** include a theme stylesheet. The URL for the stylesheet will be in the format `/_content/StellarAdmin.TagHelpers/stellar-admin.<theme>.css` - where `<theme>` is the lowercase name of the theme. The snippet below demonstrates how to include the Nova theme.

```razor
<link rel="stylesheet" href="/_content/StellarAdmin.TagHelpers/stellar-admin.nova.css" asp-append-version="true"/>
```

<Callout type="idea">
    Since the StellarAdmin Tag Helpers are based on shadcn/ui, you can also use their [Create page](https://ui.shadcn.com/create) to browse the different themes. The *Style* selector on the left-side of the _Create_ page corresponds with the eight upstream-derived StellarAdmin themes. Concourse, Ice, Ledger, Meridian, and Observatory are available through the demo picker on this site.
</Callout>


### Concourse

Concourse uses cool grey surfaces, a blue accent, compact controls, and small corners. Hover and pressed states change colour without moving the controls. Load **Source Sans 3** (UI text, weights 400, 500, 600, and 700) and **IBM Plex Mono** (identifiers and values, weights 400 and 500) from your application layout:

```razor
<link rel="preconnect" href="https://fonts.googleapis.com"/>
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin/>
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Source+Sans+3:wght@400;500;600;700&amp;family=IBM+Plex+Mono:wght@400;500&amp;display=swap"/>
<link rel="stylesheet" href="/_content/StellarAdmin.TagHelpers/stellar-admin.concourse.css" asp-append-version="true"/>
```

Replace your existing theme link with this bundle. You can self-host the fonts; the stylesheet does not fetch them. The existing tag helpers and `dark` class work unchanged. Default controls are 34px high; applications can increase touch targets through their own responsive layout.

### Ledger

Ledger uses warm paper surfaces in light mode, blue-tinted charcoal in dark mode, and raised controls. It is designed for **Lexend** (UI text, weights 300–700) and **JetBrains Mono** (monospaced content, weights 400–500). The theme sets the font families, but your application must load the fonts.

Add these links to the `<head>` of your shared Razor layout, replacing your existing theme stylesheet:

```razor
<link rel="preconnect" href="https://fonts.googleapis.com"/>
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin/>
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Lexend:wght@300..700&amp;family=JetBrains+Mono:wght@400;500&amp;display=swap"/>
<link rel="stylesheet" href="/_content/StellarAdmin.TagHelpers/stellar-admin.ledger.css" asp-append-version="true"/>
```

You can also self-host the fonts instead of using Google Fonts. No font-family override is needed, and the same `dark` class works as with other themes.

### Ice

Ice is a compact theme for operational screens: square corners, hairline borders, no elevation shadows, and blue interaction accents. Default controls are 28px high with 12.5px UI text. It uses IBM Plex Sans for labels and prose, and JetBrains Mono for data, badges, and keyboard hints.

Load its fonts and select its single stylesheet in your Razor layout:

```html
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=IBM+Plex+Sans:wght@400;500;600&amp;family=JetBrains+Mono:wght@400;500;700&amp;display=swap"/>
<link rel="stylesheet" href="/_content/StellarAdmin.TagHelpers/stellar-admin.ice.css" asp-append-version="true"/>
```

You can self-host the fonts instead. The stylesheet does not download fonts, and the normal `dark` class switches colour modes. Use the existing tag helpers; no Ice-specific markup is required. For numeric content in your own markup, use a monospace font with tabular figures. Choose larger controls where your app needs more generous touch targets.

### Observatory

Observatory is a compact operations theme with cool neutral surfaces, blue accents in light mode and cyan accents in dark mode, 4px corners, and shadowless dark cards. Default controls are 32px high and table cells use 7px vertical padding. It uses **IBM Plex Sans** (UI text, weights 400/500/600) and **IBM Plex Mono** (data and shortcuts, weights 400/500).

Load the fonts and replace your current theme link in the shared Razor layout:

```html
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=IBM+Plex+Sans:wght@400;500;600&amp;family=IBM+Plex+Mono:wght@400;500&amp;display=swap"/>
<link rel="stylesheet" href="/_content/StellarAdmin.TagHelpers/stellar-admin.observatory.css" asp-append-version="true"/>
```

You can self-host the fonts. The stylesheet does not fetch them, and the usual `dark` class switches colour modes. Use `font-mono tabular-nums` for numbers and identifiers in your own markup. Compact spacing is built in; no density setting is required. Choose larger controls where your app needs more generous touch targets.

### Meridian

Meridian uses warm paper surfaces in light mode, deep umber in dark mode, brass accents, and 2px corners. Its typography combines **Instrument Sans** (display headings, weight 600), **Work Sans** (UI text, weights 400/500/600), and **JetBrains Mono** (data and shortcuts, weights 400/500).

Load its fonts and replace your current theme link in the shared Razor layout:

```html
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Instrument+Sans:wght@600&amp;family=Work+Sans:wght@400;500;600&amp;family=JetBrains+Mono:wght@400;500&amp;display=swap"/>
<link rel="stylesheet" href="/_content/StellarAdmin.TagHelpers/stellar-admin.meridian.css" asp-append-version="true"/>
```

You can self-host the fonts. The stylesheet does not fetch them, and the usual `dark` class switches modes. Default controls are 32px high, with 26px small and 40px large variants. Tables use 11px vertical cell padding. Use `font-mono tabular-nums` for numbers and identifiers in your own markup. Choose larger controls where your app needs more generous touch targets. Dropdown checkbox and radio selections use checkmarks to the right of the text; resting selected rows have no persistent colour fill.

The CSS variables you can override are listed in the table below.

| Variable | Description |
|----------|-------------|
| `--background` / `--foreground` | Sets the base surface and text color of the application, which the page shell, page sections, and body text all inherit. |
| `--card` / `--card-foreground` | Colors raised surfaces such as the Card component, dashboard panels, and settings panels, along with the content inside them. |
| `--popover` / `--popover-foreground` | Colors overlay surfaces and their content, including Popover, DropdownMenu, ContextMenu, and similar floating components. |
| `--primary` / `--primary-foreground` | Carries the brand color through prominent elements such as the default Button, selected states, badges, and active accents. |
| `--secondary` / `--secondary-foreground` | Colors filled but quieter elements, such as secondary buttons and badges, that support the primary action without competing with it. |
| `--muted` / `--muted-foreground` | Tones down surfaces and text that should recede, such as descriptions, placeholders, helper text, and empty states. |
| `--accent` / `--accent-foreground` | Highlights elements as the user interacts with them, covering ghost buttons, hovered rows, highlighted menu entries, and selected items. |
| `--destructive` | Signals danger and error, and is applied to destructive buttons, invalid form states, and destructive menu items. |
| `--border` | Draws the borders and separators that divide cards, menus, tables, and page layout. |
| `--input` | Styles the borders and surfaces of form controls such as Input, Textarea, Select, and other outline-style controls. |
| `--ring` | Draws the focus ring that appears around buttons, inputs, checkboxes, menus, and any other focusable control. |
| `--chart-1` ... `--chart-5` | Provides the default series palette used by charts and chart-driven dashboard blocks. |
| `--sidebar` / `--sidebar-foreground` | Sets the surface and default text color of the Sidebar component and everything rendered inside it. |
| `--sidebar-primary` / `--sidebar-primary-foreground` | Emphasizes the sidebar's most prominent elements, such as active items, icon tiles, badges, and calls to action. |
| `--sidebar-accent` / `--sidebar-accent-foreground` | Marks hovered and selected sidebar elements, including menu entries, expanded items, and interactive rows. |
| `--sidebar-border` | Draws the borders and separators inside the sidebar, such as those around headers and between groups. |
| `--sidebar-ring` | Draws the focus ring around controls inside the sidebar. |
| `--radius` | Defines the base corner radius from which the `radius-*` variables are derived, shaping cards, inputs, buttons, and popovers. |


## Using the design tokens in your own app

StellarAdmin Tag Helpers apply the theme styles to all the Tag Helpers. However, sometime you may also want to use the same colors in other parts of your application. For example, you may want to use the primary background color on an element. Your first thought may be to simply use the Tailwind CSS `bg-primary` token.

```html
<div class="bg-primary">...</div>
```

The above will likely not work because your own Tailwind configuration has not declared the correct [theme variables](https://tailwindcss.com/docs/theme).

To fix this, you can copy the [`theme-tokens.css`](https://github.com/stellar-admin/stellar-admin/blob/master/src/StellarAdmin.TagHelpers/Client/css/theme-tokens.css) file from StellarAdmin Tag Helpers into your project and import it from your Tailwind entry stylesheet:

```css
@import "tailwindcss";
@import "./theme-tokens.css";
```

Once you do this, those design tokens will be used in your own Tailwind CSS configuration and you will have utility classes such as `bg-primary`, `bg-secondary`, `text-primary-foreground`, `bg-card`, etc. available to use in your own application. This will also ensure that your own application code will adapt to StellarAdmin theme changes and customizations.

## Menu surfaces

Floating menus (such as the [Dropdown Menu](/docs/tag-helpers/components/dropdown-menu) content and sub-menus) have three application-wide appearance settings, configured once in `Program.cs` by chaining `ConfigureMenu` off `AddTagHelpers()`:

```cs
builder.Services.AddStellarAdmin()
    .AddTagHelpers()
    .ConfigureMenu(menu =>
    {
        menu.Color = MenuColor.Inverted;
        menu.Appearance = MenuAppearance.Translucent;
        menu.Accent = MenuAccent.Bold;
    });
```
